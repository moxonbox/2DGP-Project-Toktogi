# 실소금쟁이류 (학명 사용) (Hydrometra martini) — 3D 외형 모델 명세서

> **기준:** `toktogi_model.md`의 외형 명세 범위(실루엣·크기·외부 기관·색채·표면·미정 수치). **대상 분류:** 종.
> **범위 주의:** 북미 연구종. 비슷한 Hydrometra 속이라도 H. stagnorum의 머리 비율과 무늬를 무조건 복제하면 안 된다.
> **톡토기 관계:** 근연 톡토기 *S. malmgreni*를 먹이로 사용한 종 실험은 확인, *S. aquaticus* 미확인.

## 1. 전체 형태

| 항목 | 3D 실루엣·구성 |
|---|---|
| 기본 실루엣 | 실 같은 가는 몸통, 길게 뻗은 머리·더듬이·여섯 보행다리. |
| 머리 | 수면 방향으로 길게 튀어나온 가는 머리; 눈이 머리 중~후방에 있음. |
| 가슴 | 좁고 긴 흉부; 몸 측면에 각 다리의 기부가 보임. |
| 배 | 폭 좁은 긴 뒷몸통, 날개형에 따라 등판 윤곽이 달라짐. |
| 입 | 아래로 접히는 관통·흡즙형 주둥이, 더듬이와 별도. |
| 날개 | 단시형/장시형 등 다형성을 점검; 이번 출처로 고정 분포비율 미정. |

## 2. 크기·성차·성장 단계

| 구분 | 값과 적용 범위 |
|---|---|
| 수컷 성체 | **7.7–8.5mm**: 1981년 미네소타 문헌의 n=10 표본. [M1] |
| 암컷 성체 | **8.8–10.15mm**: 같은 문헌의 n=10 표본. [M1] |
| 성별 | 암컷의 몸길이가 위 표본에서는 더 큼. 성별 다리·배 폭 비율은 미정. |
| 어린 개체 | 약충의 상대적 몸길이·날개싹 치수는 종별 실험 원표 확인 전 미정. |

> **치수 해석:** 위 mm/cm는 자료의 **몸길이**이며, 부속지까지 포함한 전체 외접 크기와 다릅니다. 표본·단계·측정법을 보존합니다.

## 3. 부위별 외형

| 부위 | 모델링 요구 및 근거 범위 |
|---|---|
| 머리·겹눈 | 길쭉한 머리 양쪽의 돌출 눈. 눈을 정면 끝에 배치하지 않음. |
| 더듬이 | 한 쌍이 앞쪽에서 길게 뻗음; 실제 마디별 길이 고정 미정. |
| 주둥이 | 복면에 접힌 바늘형 rostrum; 포식 시 먹이로 접촉. |
| 앞가슴 | 머리 바로 뒤의 좁은 등판, 종 구별에 쓰이는 경계선 도판 필요. |
| 흉부 | 다리 세 쌍의 부착점과 날개 기부를 위한 좁은 중앙 구조. |
| 배 | 길고 가느다란 분절된 몸 뒤; 암수 배 끝 윤곽은 따로 확인. |
| 다리 | 6개; 긴 경절·발마디를 갖는 수면 보행 자세. |
| 발 | 수면 접촉은 작은 말단을 통해 표현; 거미형 8다리 금지. |
| 날개 | 날개형별 접힌 등면 윤곽은 같은 속 자료 아닌 선택 표본으로 지정. |
| 약충 | 완전변태 유충이 아니라 성체 비슷한 작은 약충형. |

## 4. 색채·표면·재질

| 항목 | 재질·무늬 명세 |
|---|---|
| 몸 색 | 갈색~암갈색 계열의 가늘고 긴 몸; 종 특이 띠 색은 미정. |
| 다리 | 몸통과 비슷하거나 약한 색 대비, 강한 금속광/줄무늬 임의 추가 금지. |
| 눈 | 짙은 겹눈 대비; 눈 표면 미세 격자는 극근접에서만. |
| 표면 | 경질 큐티클, 부분적으로 작은 털; 수치형 거칠기는 미정. |
| 날개 | 단시형을 전장형 투명막처럼 만들지 않음. |

**재질 수치:** RGB/HEX, IOR, 금속성·거칠기·투명도, 강모 밀도는 명시된 출처에 없으면 **미정**이며 미술적 기본값을 생물 실측값으로 취급하지 않습니다.

## 5. 현미경·동정용 세부 형질

| 세부 | 구현 조건·주의 |
|---|---|
| 비교종 주의 | H. stagnorum의 “눈 앞 머리 2배” 동정식을 이 종의 확정 진단식으로 복제하지 않음. |
| 크기 표본 | n=10 표본의 범위를 세계 평균값으로 해석하지 않음. |
| 성별 끝부분 | 암수 배 끝·생식구조는 현미경 도판 확인 후 구현. |
| 알·산란 | 식물/수면 기질에 부착하는 산란형태는 Hydrometra 일반; 이 종 알 치수 미확인. |
| 먹이 | *S. malmgreni* 먹이 실험 확인; 먹이 크기와 포식자 앞다리의 비율은 별도 표본 필요. |

## 6. 필수 참조 시점·모델 변형

- [ ] 등면: 가는 체형과 다리 기부
- [ ] 측면: 접힌 로스트럼·수면 보행
- [ ] 정면: 머리 앞쪽 길이와 눈
- [ ] 암수 성체 나란히 (몸길이 자료 기반)
- [ ] 약충(별도 참고형, 정확한 비율 미정)

> 표본 사진·논문 도판은 **형태 검증용 링크**로 사용하고, 재배포 권리는 별도 확인합니다.

## 7. 메시·리깅/LOD 제안 (제작 규칙; 생물 실험값 아님)

| 하위 구성 | 권장 메시·본·상태 |
|---|---|
| body | head/thorax/abdomen 긴 축을 따로 세워 굽힘 제어. |
| legs | 3쌍 6다리, 발끝 접지 전환. |
| antennae | 2개, 끝마디의 작은 진동 가능. |
| rostrum | 수면 위 먹이 찌르기·흡즙 동작용. |
| wings | 실제 개체의 날개형 검증 전 별도 변형슬롯. |
| LOD | 작은 머리와 가는 다리 실루엣을 높은 우선순위로. |
| animation | slow_walk, detect, approach, probe, feed 제안. 속도값 지정 금지. |

## 8. 원 자료만으로 확정할 수 없는 값

- **미정:** 성별 날개형과 색무늬의 종별 차이.
- **미정:** 머리·흉부·복부·다리의 정확한 비율.
- **미정:** 안구 위치, 다리 접지·수면 보행 속도.
- **미정:** 암수 생식기 형상·알의 크기.
- **미정:** 한국 개체군 존재 여부와 *S. aquaticus* 직접 포식.
