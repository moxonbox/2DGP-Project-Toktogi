# 학명 사용 (Triaeris stenaspis) — 3D 외형 모델 명세서

> **기준:** `toktogi_model.md`의 외형 명세 범위(실루엣·크기·외부 기관·색채·표면·미정 수치). **대상 분류:** 종.
> **범위 주의:** 종 수준 암컷 자료가 비교적 풍부하다. 수컷 성체가 확립되어 있지 않으므로 수컷형 모델은 만들지 않는다.
> **톡토기 관계:** 다른 톡토기류 포획 실험은 있으나 물알둥근톡토기 직접 실험은 없음.

## 1. 전체 형태

| 항목 | 3D 실루엣·구성 |
|---|---|
| 실루엣 | 작고 단단한 외골격을 가진 2구역 거미: 윤곽이 도드라진 머리가슴과 길쭉한 타원 배. |
| 두흉부 | 배보다 앞쪽의 둥근 머리가슴, 측면에서 앞쪽이 높고 뒤쪽은 낮아짐. [T2] |
| 배 | 짙게 경화된 등쪽 scutum이 보이는 타원형; 육상 낙엽틈의 소형 배회형. |
| 팔다리 | 보행다리 4쌍, 촉지 1쌍; 더듬이·날개·먹이 포획용 거미줄 없음. |
| 눈 | 머리 앞쪽 6안, 일반 거미 템플릿 8안 복사 금지. |
| 암수 | 관찰·기재된 성체는 암컷이며 수컷 형태는 별도 근거 없음. |

## 2. 크기·성차·성장 단계

| 구분 | 값과 적용 범위 |
|---|---|
| 성체 암컷 자료 | 1.8mm(유럽 종 카드), 1.47mm(미국 박물관 표본), 1.7mm(오스트리아 표본). [T1][T2] |
| 성체 수컷 | 미발견/미기재; 임의 모델 및 수컷 크기 설정 금지. |
| 유체·알 | 정확한 외형 크기 비율은 종 생활사 원표·표본 없이는 확정 불가. |
| 기준 | 몸길이로 기재된 수치이며 다리 펼친 크기와 구분. |

> **치수 해석:** 위 mm/cm는 자료의 **몸길이**이며, 부속지까지 포함한 전체 외접 크기와 다릅니다. 표본·단계·측정법을 보존합니다.

## 3. 부위별 외형

| 부위 | 모델링 요구 및 근거 범위 |
|---|---|
| 머리가슴 | 광택 있는 담주황~황적색 등판; 둥근 뒷모서리, 앞쪽은 약간 좁음. [T2] |
| 눈 | 눈 6개를 실제 안구군으로 배치; 위치·직경은 표본 정면/등면 도판 필요. |
| 협각 | 작은 아래향 독니 한 쌍; 먹이 접촉 시 작동하도록 분리. |
| 촉지 | 머리 앞쪽의 짧은 한 쌍. 미기록 수컷 교미촉지로 확장 금지. |
| 배 등면 | 주황빛 몸 위에 **진한 적갈색 경화 등판(scutum)**; 배 전체를 완전 검정 갑각으로 만들지 않음. [T1] |
| 배 복면 | 복면 경화판 및 암컷 생식기관을 위한 별도 저폴리 디테일. |
| 다리 I·II | 앞다리 무릎마디(patella) **가시 3쌍**, 경절(tibia) **5쌍**. [T1] |
| 발허리마디 | 앞다리 I·II metatarsus에는 종 카드상 가시가 없음. [T1] |
| 뒷다리 | III·IV는 일반 보행관절; I·II 가시 규칙을 자동 복제하지 않음. |
| 실젖 | 복부 후단의 작은 기관; 주로 이동 실 등에 사용, 먹이 포획그물 생성을 기본 상태로 두지 않음. |

## 4. 색채·표면·재질

| 항목 | 재질·무늬 명세 |
|---|---|
| 바탕 | 머리가슴과 다리는 담주황~황갈색; 정확한 RGB 미정. |
| 등판 | 배 등쪽 scutum은 적갈색~진한 붉은갈색, 주변은 상대적으로 연한 부분. |
| 표면 | 경화 등판은 비교적 매끈하고 빛 반사가 있음; 몸 전체를 유리질로 처리하지 않음. |
| 털 | 희박한 미세 강모·바늘형 털. AMNH 표본에는 머리가슴 표면의 세부 미세 요철이 기술됨. [T2] |
| 개체 변이 | 조명·표본 보존 상태·탈피 후 경화에 따라 색조가 달라짐. |

**재질 수치:** RGB/HEX, IOR, 금속성·거칠기·투명도, 강모 밀도는 명시된 출처에 없으면 **미정**이며 미술적 기본값을 생물 실측값으로 취급하지 않습니다.

## 5. 현미경·동정용 세부 형질

| 세부 | 구현 조건·주의 |
|---|---|
| 눈 수 | 6안 표준을 도판과 재확인. 다른 알거미과 종으로 교체 시 새 검색표 적용. |
| 앞다리 가시 | 경절·무릎의 가시 수는 **마디마다** 적용하며 한 다리 전체 합계로 오기 금지. |
| 경화판 | 등면/복면 경화판 경계는 구분되지만 종 개체의 경계 좌표는 미정. |
| 다리 마디 | 메타타르수스와 타르수스를 하나로 합치지 않음. |
| 암컷 생식부 | 정밀/학술 LOD에서만 원표 도판을 확인 후 표시. |

## 6. 필수 참조 시점·모델 변형

- [ ] 등면: 머리가슴과 배 경화판의 면적 경계
- [ ] 정면: 6안 및 협각
- [ ] 측면: 앞쪽 머리가슴 높이와 배 경화단면
- [ ] 복면: 흉판·복면 경화판·암컷 생식부
- [ ] 앞다리 I·II 경절·무릎 가시 확대

> 표본 사진·논문 도판은 **형태 검증용 링크**로 사용하고, 재배포 권리는 별도 확인합니다.

## 7. 메시·리깅/LOD 제안 (제작 규칙; 생물 실험값 아님)

| 하위 구성 | 권장 메시·본·상태 |
|---|---|
| prosoma/abdomen | 분리 결합, 좁은 허리 연결. |
| leg_1..4 | 관절 본 및 앞다리 I·II의 가시 부착. |
| chelicerae | 작은 접촉-물기 이동만 허용; 정확한 속도 미정. |
| scuta | 배 외피 위 별도 재질 ID; 단단한 판과 부드러운 부분의 광택 차이. |
| palps | 암컷 성체형만 기본 프리셋 제공. |
| LOD | 고배율에서 가시·6안 유지, 원경에서 스큇 텍스처와 실루엣 우선. |
| animation | ground_search, grasp_hold, repeated_bite 제안; 수면 활주 기본값 금지. |

## 8. 원 자료만으로 확정할 수 없는 값

- **미정:** 수컷 성체 몸 형태·교미기관(미기재).
- **미정:** 6안의 정확한 배치와 크기·강모 밀도.
- **미정:** 스큇 경계/몸 비율과 다리 외접 폭.
- **미정:** 산란 낭의 정확한 실루엣·위치.
- **미정:** *S. aquaticus* 포식 장소/기작·수면 활동.
