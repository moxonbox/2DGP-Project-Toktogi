# 물알둥근톡토기 행동·움직임 명세서

> **문서명:** `toktogi_movement.md`  
> **버전:** 1.0  
> **작성일:** 2026-11-03 (한국 시간)  
> **대상:** 물알둥근톡토기, *Sminthurides aquaticus*  
> **기준 자료:** 첨부 `toktogi(2).md` v1.0(2026-11-02), 이를 대조·보완한 외부 연구·관찰 자료, 31개 장면의 움직이는 행동도감  
> **목적:** 확인된 행동과 표현상의 한계를 요약하고, 애니메이션 제작·검토에 사용할 공통 기준을 제공한다.

## 1. 범위와 핵심 요약

이 문서는 기존 조사 결과를 **31개 장면, 6개 범주**로 정리한 요약 명세다. 장면에는 행동뿐 아니라 정지 자세, 개체 간 접촉, 발육 과정, 수동적 이동도 포함한다. 따라서 31개는 표시 단위이며, 이 종의 모든 행동이 완전히 밝혀졌다는 뜻은 아니다.

| 범주 | 장면 수 | 번호 |
|---|---:|---|
| 수면 생활 | 4 | 01–04 |
| 섭식·몸 손질 | 5 | 05–09 |
| 개체 간 접촉 | 7 | 10–16 |
| 구애·정포 전달 | 7 | 17–23 |
| 산란 | 4 | 24–27 |
| 발육·분산 | 4 | 28–31 |
| **합계** | **31** | **01–31** |

핵심은 **수면 보행·furca 도약**, **한쪽 세 다리 지지 그루밍**, **더듬이 결속과 암컷의 수컷 운반**, **산란홈 만들기·산란·배설물 덮기**다. 각각의 근거와 세부 제한은 아래 목록 및 참고문헌에 연결한다.

## 2. 근거와 표현 방식

근거 수준과 화면의 표현 방식은 별도로 기록한다. 연구에 등장하는 행동도 실제 움직임 전체가 측정되었다는 뜻은 아니다.

| 근거 표시 | 의미 |
|---|---|
| 연구 | 종이 명시된 논문의 서술·현장 기록·사진. 행동학적 정량 실험인지 여부는 별도 구분한다. |
| 관찰 | 촬영자·관찰자가 기록한 사진, 연속사진, 영상 또는 직접 설명. 빈도·원인까지 확정하지 않는다. |
| 캡션 | 종별 사진에 붙은 설명. 정지 자세를 넘어선 연속 동작과 행동 목적은 주의해서 해석한다. |
| 일반·재인용 | 상위분류의 일반 과정 또는 고전 문헌의 재인용. 종 특이 수치·순서로 고정하지 않는다. |

| 표현 표시 | 적용 기준 |
|---|---|
| 관찰 재구성 | 관찰된 행동을 그림으로 설명한다. 관절 각도와 연결 동작은 단순화할 수 있다. |
| 사진 자세 재구성 | 사진의 자세를 중심으로 표현한다. 사진 앞뒤 움직임은 보간임을 밝힌다. |
| 기전 모식도 | 기관의 위치·작동 관계를 설명한다. 속도·궤적·힘의 실측 재현이 아니다. |
| 개념도 | 정포 전달, 발육, 분산 등 확인 범위가 제한된 과정을 설명한다. 상세 동작은 확정하지 않는다. |

## 3. 형태·기관 표현 기준

| 대상 | 명세 |
|---|---|
| 몸체 | 머리와 둥근 몸통을 구분하고 다리는 세 쌍, 총 여섯 개로 표현한다. 날개는 없다. |
| 암수 | 성체 구애 장면에서 암컷은 크게, 수컷은 작게 표현한다. 고정 질량비·운반 하중으로 환산하지 않는다. [R2] |
| 더듬이 | 한 쌍의 마디 있는 더듬이. 수컷의 변형된 더듬이는 암컷 더듬이와 결속하는 기관이다. [R1] · [R2] |
| furca | 배 아래에 접혀 있다가 펴지는 도약기관. 넓어진 말단이 수면 접촉에 관련된다. [R1] |
| 복관 | 배쪽의 수면 접촉 기관으로 구분한다. 접촉 관찰을 곧바로 착지 제어·흡수 능력의 증거로 확대하지 않는다. [O3] |
| 색·크기 | 관찰을 돕는 모식적 표현으로 취급한다. 색만으로 성별·종을 동정하지 않는다. |

앞·가운데·뒷다리와 좌우를 구분할 수 있어야 한다. 좌우는 관찰자의 화면 방향이 아니라 **개체 자체의 좌우**를 기준으로 한다.

## 5. 핵심 동작 연결 규칙

### 5.1 그루밍

**여섯 다리 지지 → 왼앞·왼중간다리를 들어 더듬이 청소(네 다리 지지) → 왼뒷다리도 들어 furca 청소(오른 세 다리 지지).** 이 연결은 해당 관찰 기록의 순서다. 모든 개체의 필수 동작이나 빛에 대한 확정 반응으로 일반화하지 않는다. [O2]

### 5.2 구애와 결속 도약

접근·더듬이 결속·운반·방향 전환을 구분해 표현한다. 운반 또는 도약 중에는 **더듬이 연결 관계**가 유지되어야 하며, 도약 추진은 **암컷의 furca**로 표현한다. 장면을 이어 보여 주더라도 실제 개체가 언제나 같은 순서·횟수로 행동한다는 뜻으로 표시하지 않는다. [R2] · [O3]

### 5.3 산란

**잎 표피를 입으로 씹어 홈 만들기 → 홈에 산란 → 배설물 펠릿으로 알 덮기**는 직접 관찰된 순서다. 알·펠릿을 입에서 내놓거나 앞다리로 흙을 모아 덮는 장면으로 바꾸지 않는다. [O1]

### 5.4 정포·탈피·발육

정포 전달은 별도 개념도로 설명한다. **정포 수용 → 반드시 탈피 → 산란**을 필수 순서로 고정하지 않는다. 관련 고전 재인용과 상위분류 설명은 추가 원전 검증이 필요하다. 배아·부화·탈피도 별도 과정으로 표시한다. [O1] · [R2]

## 6. 애니메이션 제작·재생 명세

1. **장면 정보:** 번호, 고유 ID, 이름, 범주, 근거, 표현 방식, 핵심 동작, 해석 한계, 출처를 유지한다.
2. **기관 구분:** 여섯 다리·더듬이·furca·복관을 구별한다. 결속점과 도약 추진점이 섞이지 않게 한다.
3. **접지 구분:** 그루밍에서 지지 다리는 수면에 닿고 손질 다리는 들어 올린 상태가 보이게 한다.
4. **시간·물리량:** 재생 시간, 보폭, 관절 각도, 도약 궤적, 화면상의 크기는 설명용이다. 생물의 실측 성능으로 표시하지 않는다.
5. **사진 기반 장면:** 자세 사이 움직임은 보간임을 표시한다. 정지 사진을 정밀한 연속 관찰로 소개하지 않는다.
6. **미확인 목적:** 접촉·집합·알 주변 머무름에 공격성, 학습, 협력, 육아 등의 목적을 임의로 추가하지 않는다.

## 7. 미확인·해석 제한

- **수치:** 최대 도약 거리·속도·높이, 공중 회전·착지 성공률, 운반 하중, 수명, 부화·성숙 소요일, 탈피 횟수, 평생 산란수는 확정값으로 기재하지 않는다.
- **행동 목적:** 암수 간·동성 간 접촉의 동기, 유체의 학습, 알 주변 머무름의 보호 효과, 집합의 사회성은 이번 자료만으로 확정하지 않는다.
- **생활 환경:** 수면 생활을 상시 잠수·수중 유영으로 확대하지 않는다. 정지 자세를 잠·휴면으로 판단하지 않는다.
- **발육·번식:** 고전 문헌에서 재인용된 탈피 사이 산란수를 평생 산란수로 쓰지 않는다. 정포·탈피·산란의 세부 관계는 원전 확인이 필요하다.
- **분류 범위:** 속 수준의 규조류 섭식이나 다른 톡토기 종의 도약·착지 실험값을 이 종의 확정 속성으로 옮기지 않는다.
- **추가 조사:** 새 행동을 추가할 때는 종명, 성별·발육 단계, 관찰 조건, 자료 형태, 직접 확인 범위와 출처를 함께 기록한다.
