톡토기 128×128 게임 스프라이트 — 정밀 검토 개선 적용

출력과 동작
- 한 방향의 좌향 3/4 시점입니다. 한 칸 128×128px, 투명 PNG 24프레임입니다.
- 시트는 1024×384px, 8열×3행입니다. 위에서부터 idle / walk / jump입니다.
- idle: 8프레임, 8fps, 반복. walk: 8프레임, 12fps, 반복. jump: 8프레임, 12fps, 한 번 재생.
- jump의 처음과 마지막은 idle_00과 픽셀까지 같습니다. 실제 이동과 점프 궤적은 엔진에서 처리합니다.

이번 개선
- 최종 외곽선을 명목상 2px에서 3px로 늘렸습니다. Blender의 256px 렌더에서는 Freestyle 6px입니다.
- 카메라 반대쪽 앞다리의 자세를 조정해 턱 옆에서 조금씩 나타나던 돌출을 없앴습니다. 전체 24프레임에서 해당 부품의 표면이 가려집니다.
- 도약기관은 대기·걷기에서 뒤로 접고, 도약 중 펼칩니다. 현재 시점의 보이는 표면은 대기·걷기 0px, 도약 중 최대 57px입니다.
- 뒷발 Claw 본의 기준 방향을 실제 발끝에 맞췄습니다. 기존 변형 행렬을 보존하며 세 액션을 재베이크했습니다.
- 메시 정점/면 수, UV 좌표, Mark Seam, 웨이트, 본 이름과 부모 계층, 머티리얼 구조와 텍스처는 유지했습니다. 본의 기준 방향과 액션 키는 보완했습니다.
- 몸통·머리의 둥근 비율, 굵은 더듬이·다리, 약한 웨더링과 고정 눈 하이라이트를 유지했습니다.
- 스프라이트 렌더를 512샘플로 올렸습니다. 디더링·모션 블러·애니메이션 시드·디노이징은 사용하지 않습니다.
- 1~2px의 완전히 둘러싸인 투명 구멍을 정리하는 후처리를 추가했습니다. 이번 출력에서는 자세와 선 조정으로 해당 구멍이 이미 없어 추가로 채운 픽셀은 0개입니다.
- 도약 한 프레임의 가는 불투명 끝점 1px를 제거했습니다. 큰 부품 사이 공간은 보존했습니다.
- 투명 픽셀의 RGB 확장은 마지막에 다시 계산합니다. 보이지 않는 RGB 변화는 동작 변화량에 포함하지 않습니다.
- 텍스처 외부 경로를 //toktogi_rigged_basecolor.png로 바로잡았으며 이미지도 .blend에 포함했습니다.

게임 적용
- Point/Nearest 필터, mipmap 끄기, 손실 압축 끄기. 정수 배율과 픽셀 정렬을 유지하십시오.
- 시트는 128×128 Grid로 나눕니다. 자동 Trim은 끄거나 고정 피벗을 보존하십시오.
- 피벗은 위 기준 (64,88)px, 정규화 좌표 (0.5,0.6875)입니다.
- Unity 아래 기준 Custom Pivot은 (0.5,0.3125), Godot centered offset은 (0,-24)px입니다.
- 엔진용 Pixels Per Unit은 128로 시작할 수 있습니다. 렌더 모델 단위 환산값은 별도 메타데이터입니다.
- walk는 12fps에서 약 9.44px/s의 작은 보폭입니다. 엔진 이동 속도를 바꾸면 재생 속도도 맞추십시오.
- 조명과 음영이 PNG에 구워져 있습니다. 2D Unlit 재질로 확인하십시오.
- 우향은 수평 뒤집기로 사용할 수 있으며 구워진 조명과 비대칭도 함께 뒤집힙니다.

Blender에서 재출력
- Text Editor의 EXPORT_SPRITES.py를 실행합니다. 현재 .blend 폴더에 시트·개별 PNG·JSON·APNG를 다시 출력합니다.
- 같은 이름의 이미지와 메타데이터를 덮어씁니다. 이전 출력이 필요하면 다른 폴더에 .blend를 복사하십시오.
- F12는 중간 단계인 256px 렌더입니다. 128px 팔레트·알파 후처리는 내장 스크립트가 수행합니다.
- SET_SPRITE_CLIP.py의 CLIP을 idle / walk / jump로 선택한 뒤 실행하면 액션·범위·FPS를 함께 맞춥니다.
- 액션마다 sprite_fps 속성도 기록했습니다. 장면의 기본 상태는 idle, 8fps입니다.
- 재출력의 이미지 검사는 toktogi_sprite128_export_validation.json에 기록합니다. 배포본의 상세 검증 JSON은 덮어쓰지 않습니다.
- 모델이나 액션을 수정하면 기존 상세 검증은 수정본에 대한 검증이 아닙니다. 리그·UV·접지는 별도로 재검사하십시오.

검증
- 2,732삼각형, 37본. UV 겹침·열린 경계·미할당 웨이트 0.
- 0.25프레임 간격 총 95포즈에서 비인접 면 교차 0.
- 루프 연결 정점 오차 약 2.16e-7 모델 단위.
- 접지 102표본의 실제 발바닥 높이는 -0.332~+0.359px 환산 범위.
- 24프레임 모두 불투명 실루엣이 4방향·8방향 기준 각각 하나이며, 떠다니는 조각과 가는 끝점 후보가 없습니다.
- 1~2px 투명 구멍 0. jump_05의 7px 부품 사이 공간 하나는 보존했습니다.
- 최종 알파는 0 또는 255이며, 최소 투명 여백은 7px입니다.
- 눈 하이라이트 최소 9px. 시트와 개별 PNG 픽셀 일치, PNG CRC·APNG 구조 검사 통과.
- 동일 포즈 반복 렌더의 픽셀 차이 0.
- .blend를 다른 폴더로 옮긴 재출력도 바이트 일치. 상세 검증 보고서와 걷기 속도 메타데이터 보존 확인.

한계
실제 게임 엔진·게임 배경에서 재생하지 않았습니다. 충돌체·이동 로직·엔진별 자동 임포터는 포함하지 않았습니다.
한 방향의 대기·걷기·도약입니다. 다른 시점과 새 동작은 별도 검증해야 합니다.
