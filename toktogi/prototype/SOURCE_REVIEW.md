# 톡토기 프로젝트 자료 검토와 프로토타입 적용

gameplay-r1 보완: 구체적인 수정·잔여 범위와 재현 결과는 PATCH_NOTES.md 및 regression_results.json을 우선 확인합니다. 아래 자료 조사 내역은 초기 제작 기록을 포함합니다.

기준일 2026-11-14. 지정 프로젝트의 `.git` 제외 81개 파일을 조사했습니다. `asset` 폴더는 비어 있었고 실행 소스는 확인되지 않았습니다. 구현은 v2.1과 integrated-r5에 맞춰 독립 실행할 수 있게 만들었습니다.

## 발표 자료·에셋 대조

- 60쪽 기획서 PDF와 `presentation/01_2DGP_toktogi_spec.pdf`는 SHA256이 같습니다. 10쪽 발표자료 PDF를 별도로 확인했습니다. 둘 다 이미지 페이지로 구성되어 페이지 이미지를 읽었습니다. 세 PPTX의 각 슬라이드가 참조하는 이미지와 대응 PDF를 페이지 순서로 비교했습니다. 8비트 RGB 축소 비교에서 최대 평균 절대차는 0.67입니다.
- 60쪽 중 p.5–8의 흐름·확정 조건, p.19–26의 입력과 소유권, p.28–34의 속도 합산·탄성·Capsule, p.36–43의 재질·색/수치·비용, p.45–50의 검증·양산 관문을 구현에 반영했습니다. p.15·24·52–55의 번식/관계/발육, 10쪽 발표본의 성장·구버전 상태는 최신 범위와 대조했습니다. 장기 성장·관계 물리는 게임 코스에 활성화하지 않았습니다.
- 상태 머신 이미지 2개와 `doc/reference`의 조사 이미지·GIF는 이전 시각 자료입니다. `presentation/image/material_examples`의 Base/Alpha, Normal, Roughness, Metallic, 좌우 조명 예제는 재질 반응 비교 기준입니다. 발표 PNG ZIP의 CRC를 확인했습니다. `.af`는 발표 편집 원본으로 분류했습니다. 내용은 PDF/PPTX 출력에서 확인했습니다.
- `blender`의 원본은 24개 셀·3개 모션·단일 뷰의 이전 패키지입니다. JSON·README는 고정 Nearest와 피벗, 단일 방향 및 베이크 조명을 기록합니다. ZIP과 단독 시트·프레임·검증 자료는 역추적에 사용했습니다. 그 자료의 `mirror_for_right`를 새 패스에 적용하지 않습니다.
- 실제 실행은 integrated-r5의 원본 manifest·45장 맵을 사용합니다. 서명과 각 PNG SHA256을 대조한 뒤 128px 셀별로 동일한 RGBA를 묶었습니다. 그 결과는 82개 클립, 지원 뷰 조합 212개, 고유 출력 셀 1,444개, 시퀀스 17개·804셀입니다. 06–07 연결의 경계 홀드는 제공된 구간 정의를 따라 47셀·3.96초로 재생합니다.

## 실험 규칙과 검증 상태

| 항목 | 구현·시험 |
|---|---|
| 입력·시간 | SDL queue timestamp를 첫 120Hz 경계에 배치하고 큰 dt의 미처리 시간을 보존. Space DOWN은 이전 작업·미발사 요청 취소, 새 UP은 일반 준비 0.08초. 포커스 상실·모드 전환에서 유지 입력을 해제. Pause 중 시뮬레이션 정지 |
| 운동 | 가속·제동·지지 상실·벽/천장·발판의 Capsule 접촉. 실제 가로 속도에 도약 성분을 합산. 회복 중 걷기 13.2px/s 대 일반 24px/s, 재도약 성분 0.82. 픽셀 좌표 중력 850px/s². 발판 표면은 물리 기준점으로 사용하고 3/4 이미지의 앞뒤 발 높이는 폭이 있는 상판으로 표시 |
| 탄성 잎 | 이전 100ms, 이후 165ms의 전용 Space UP 창. 실제 지지 재확인·요청 단일 소비. 정상/탄성 상승 초기값은 각각 426/541px/s. 시각 머티리얼과 탄성 판정 분리 |
| 작업·진행 | 작업점에서 3.5px 이내인 등불·먹이·씨앗, 손질, active hit/hurt box로 검사하는 정적 가시 공격·피격, 체크포인트와 목표. 목표 발판 지지, 등불 플래그, 저속 0.20초 필요. 아래 회수 발판과 이탈 실패 구역 구분. 재시작은 실행 문맥 초기화 |
| 표시 | 코스 1×, 검수 1×/2×/3× Nearest. 플레이 자세는 좌·우, 검사 화면은 원본 지원 뷰 전부. 지원하지 않는 뷰를 수평 반전하거나 임의로 채우지 않음 |
| 조명 | `lit`은 camera-space Normal, 정규화 Blinn–Phong/Schlick 근사, 평면 점광원 거리 감쇠, sRGB 출력. 플레이는 캐릭터 추적 광원과 주변광, 단색 바탕과 접지 그림자를 사용. 검수는 광원 제어와 물성 덮어쓰기를 지원 |
| 실행 비용 | 맵은 셀 ZIP에서 현재 프레임 단위로 읽음. 맵 36셀·전처리 픽셀 24셀·상대 광원과 물성별 완성 Surface 96셀 캐시. 전체 45장을 실행 메모리에 두지 않음. `verification.json`의 시간은 이 호스트의 SDL dummy 이며 실제 창과 다른 장치의 측정이 필요 |

`main.py --verify`의 키 입력 재생으로 한 코스에서 4회 도약, 1회 탄성 성공, 등불 활성화, 가시 제거, 정상 목표 도달과 체크포인트 재시작을 확인했습니다. 포커스 및 Pause, 정상/탄성 앞 타이밍, 낙하, 회복 재도약, 작업 바인딩과 발광·Normal·광원·물성 변화도 확인했습니다. 모든 셀에서 원본 Sprite의 최종 실루엣 Alpha를 보존했습니다. 동적 셰이딩의 값 변화는 `verification.json`에 기록했습니다.

이 구현은 DEC-06의 특정 실험 프로필입니다. 임의 지형과 이동 발판, 런타임 IK, 저장 복원, 복수 조명과 3D 가림, 정식 장치별 성능 수락 시험은 남아 있습니다. 검수 화면은 보간된 3D 메시 자체를 평가하지 않습니다. 수정하지 않은 r5 포즈의 기존 교차 또한 별도 에셋 작업입니다.

최신 3D 원본과 원본 패스는 프로젝트 blender/integrated-r5로 동봉하고 구 24셀 배포와 ASSET_INDEX.md로 구분합니다. 게임 ZIP 및 원본 manifest/Blender 해시는 toktogi_assets.source.json에 고정합니다. 원본 r5의 UV·웨이트·리그·다섯 패스와 시퀀스는 수정하지 않았습니다.
