# *Hydrometra stagnorum* — 2DGP 생물 명세서

> **범위:** 유럽의 수면성 실소금쟁이과(Hydrometridae) **종**. 프랑스 자연관찰 사진에서 *Sminthurides aquaticus*를 섭식한다고 설명한 **종명 기재 사진 기록**이 있다. 다만 표본/원자료에 근거한 **양측 종의 독립 동정·반복 검증은 미확인**이다. [T01]

## 1. 분류·동정 수준
- 동물계 → 절지동물문 → 곤충강 → 노린재목(Hemiptera) → 실소금쟁이과 → *Hydrometra* → ***Hydrometra stagnorum* (Linnaeus, 1758)**. [T02][T04]
- `toktogi`는 ***Sminthurides aquaticus***를 의미한다. 사진 캡션의 표기를 기재하되, 현미경 동정표나 표본 번호가 없는 기록은 **사진 관찰 A-사진(재검증 필요)**으로 관리한다. [T01]
- ***H. martini***는 북미에서 *S. malmgreni*를 먹이로 제공한 별개의 **사육실험 종**이므로 혼동하지 않는다. [T05]

## 2. 크기·외형·감각
| 항목 | 종 수준 확인 정보 |
|---|---|
| 몸길이 | **9–12.5 mm**(독일 종 카드) / 영국 **약 9–13 mm**; 국가·표본 조건에 따른 문헌 범위. [T02][T03] |
| 체형 | 매우 가늘고 긴 막대형 몸통, 기다란 머리, 가늘고 긴 여섯 다리·더듬이. [T02] |
| 체색 | 어두운 회갈색~흑갈색, 등쪽 연한 세로선이 보고됨. [T02] |
| 머리·눈 | 눈은 머리 가운데보다 뒤쪽에 있으며, **눈 앞 머리 길이가 눈 뒤보다 약 두 배**인 것이 유사종 감별 단서. [T02] |
| 날개형 | 날개가 짧은 개체가 흔하고 장시형은 드묾. 일반적 비행 능력을 상수로 설정하지 않음. [T02] |
| 입 | 짧게 접힌 **관통·흡즙형 주둥이(rostrum)**로 먹이를 찔러 체액을 섭취. [T03] |
- 유럽산 ***H. gracilenta***와 유사해 상대적 머리 길이, 몸길이, 부속지와 성체 생식구조를 함께 대조한다. [T02][T04]

## 3. 분포·미세서식지
- **유럽·북아프리카·중앙아시아까지** 보고되는 종이며, 물이 느리게 흐르거나 정체된 연못·습지·도랑의 **얕은 가장자리**에 서식한다. [T02][T03]
- 수면 위, 흙·돌·젖은 식물, 수면 위로 나온 줄기를 오가며 활동한다. 식물·수면 가장자리 사이 이동을 구분해 기록한다. [T02]
- **한국의 이 종 출현은 이번 자료에서 확인되지 않음**. 한국산 *Hydrometra*를 무조건 이 종으로 동정하지 않는다.
- 비교적 잔잔한 수면과 부유물 주변이라는 점에서 `toktogi`의 서식 구조와 유사하다. 두 종의 한국 내 자연 동시출현은 미확인.

## 4. 이동·사냥·먹이
- 수면을 **천천히 걸으며**, 물 표면의 진동으로 작은 절지동물의 존재를 탐지하고 접근한다. [T03]
- 생물·사체가 수면에 걸려 있을 때 **사냥과 청소(scavenging)**를 모두 수행할 수 있다. 때로 먹이를 물가로 끌고 가서 흡즙한다. [T02][T03]
- 포획 흐름: `수면진동 탐지 → 방향 조절 → 천천히 접근 → 주둥이 찌르기 → 흡즙 → 이탈`. 속도·거리·성공률은 **종별 측정치 미확보**.
- 자연사 사진의 캡션은 프랑스 오트사부아 **Beaumont**에서 ***S. aquaticus* 섭식**을 명시한다. 촬영일·정량 반복·독립 종 동정 정보는 해당 페이지에서 확보되지 않았다. [T01]
- 작은 곤충·모기 유충 등 수면에 닿는 생물도 먹지만, *S. aquaticus*가 주식이라는 정량 식단 분석은 없다. [T03]

## 5. 번식·성장·계절
- 식물·수면 위로 나온 지지물에 **알을 하나씩 세워 부착**하는 행동이 2024년 종 수준 연구에서 확인됐다. [T04]
- 2024년 관찰한 알의 크기는 길이 **약 0.869–1.10 mm**, 너비 **약 0.248–0.314 mm**. **알의 길이**를 톡토기 성체 체장과 동일 개념으로 비교하지 않는다. [T04]
- 알 → 약충 → 성충의 **불완전변태**; 종별 령 수·부화기간·난수·최대 수명은 자료 없이 고정하지 않는다.
- 독일 관찰 카드에서는 **연 2세대가 겹치는 경우**와 돌·표류물 아래에서 성충이 월동하는 지역 사례를 기술한다. 전 세계 공통값 아님. [T02]
- 종별 발육 최적 수온과 톡토기 먹이량에 따른 번식력은 **미확인**.

## 6. 먹이망·`toktogi` 관계
| 관계 | 근거·판정 |
|---|---|
| *S. aquaticus* → *H. stagnorum* | **사진·캡션 보고:** 두 종명과 섭식 행동 기재, **독립 동정·반복 재검증 필요** [T01] |
| 작은 수면 곤충·모기 유충 → *H. stagnorum* | **수면 포식·청소의 자연사 근거** [T02][T03] |
| *S. malmgreni* → *H. martini* | **다른 *Hydrometra* 종**을 이용한 2000년 사육실험 [T05] |
| 한국 물알둥근톡토기 ↔ *H. stagnorum* | **동시 출현 미확인**: 프랑스 사진을 국내 관찰로 전용 금지 |
- 먹이 섭취와 수면에서의 단순 접촉은 구분한다. 다른 종의 시험실 생존율을 이 종의 포식률로 전용하지 않는다.

## 8. 검증 과제
- [T01] 사진의 **포식자 형태(눈 앞/뒤 머리 길이, 날개·성별)** 및 톡토기 특수 더듬이·도약기관·몸 형태를 독립 동정.
- 촬영일·먹이 상태(생체/사체)·연속 흡즙 장면·위치·원본 메타데이터 확보; 허가 없는 사진 재배포 금지.
- 국내 2DGP 시뮬레이션에서는 이 종의 **한국 출현 사실부터 별도 검증**, 타 지역의 종과 자동 연결 금지.
