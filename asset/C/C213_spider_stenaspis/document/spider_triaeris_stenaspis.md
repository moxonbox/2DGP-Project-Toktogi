# *Triaeris stenaspis* — 2DGP 생물 명세서

> **범위:** 알거미과(Oonopidae)의 단일 **종**. 톡토기를 선호하는 포식성과 암컷 단위생식은 종 실험으로 확인됐으나, `toktogi`(*Sminthurides aquaticus*) 직접 포식이나 자연 연못 서식은 **미확인**이다.

## 1. 분류·이름·근거
- 동물계 → 절지동물문 → 거미강 → 거미목 → 알거미과 → ***Triaeris stenaspis* Simon, 1892**. 검증된 표준 국명이 없어 학명 사용. [T01]
- 원기재 학회지의 **1891년 권 표기**와 실제 발행 **1892년**을 구별. 일부 논문 초록의 `stenapsis`는 `stenaspis`의 오기. [T01][T11]
- 근거 수준: `[종 실험]` 사냥·번식 직접 실험 / `[종 표본]` 동정·크기·분포 / `[상위분류]` 알거미 일반 / `[미확인]` 대상 톡토기와의 관계.

## 2. 크기·외형·동정
| 요소 | 확인 내용·제한 |
|---|---|
| 몸길이 | 성체 암컷 **약 1.8 mm**(유럽 종 카드), **1.7 mm**(오스트리아 표본), **1.47 mm**(AMNH 표본). 모두 **각 출처의 표본·기록 사례**, 세계 범위/평균 아님. [T02][T08][T10] |
| 성별 | **성체 수컷 표본 미보고**; 수컷이 생물학적으로 절대 불가능하다는 의미는 아님. 수컷 외형·구애는 미상. [T01][T04] |
| 몸·색 | 작고 황적색·주황빛 머리가슴, 짙은 적갈색 배 경화판(scutum). 유체·성체의 경화 상태 차이. [T02][T07] |
| 눈 | **6안**으로 기술; 흔한 8안 거미를 그대로 복제하지 말 것. [T07] |
| 다리 | 8개. 제1·2다리 **경절(tibia) 가시 5쌍, 무릎마디(patella) 3쌍**, 발허리마디의 가시 부재가 종 카드에 제시됨. 현미경으로 재확인. [T02] |
| 생식·기타 | 암컷 복면 경화판·생식기관과 등면 경화판이 동정에 유용. 체중·최대속도·독량·다리 편 길이의 종 표준값 미확인. [T02] |
- 동정: `몸길이·등/복면 경화판 → 눈·앞다리 가시 → 암컷 생식기관 → 전문 검색표`; 색상 하나만으로 확정하지 않는다.

## 3. 분포·서식 환경
- **기원 추정:** 과거 신대륙 기원설과 서아프리카 기원 가능성 등 해석이 있으며, 자생 분포를 단정하지 않는다. [T01][T07]
- **보고된 출현:** 아프리카와 북·중·남미·카리브·유럽 온실·타이완·호주·태평양 지역 등. 여러 지역의 온실·식물원에서 도입 기록. [T01]
- **미세서식:** 낙엽층·표토·돌 밑·화분 기반 등 습한 온실의 지표 틈. 영국·핀란드·오스트리아 온실 표본 사례. [T07][T08]
- **한국 야외·자연 연못/개구리밥 군락 출현:** 이번 조사 자료에서 **미확인**. 높은 습도에서 발견된 사실만으로 수면 보행 능력이나 최적 온습도 수치를 확정하지 않는다.

## 4. 일상·사냥 행동(2014 종 실험)
- 그물로 먹이를 가두지 않는 **배회·직접 포획형**: `접근 → 앞에서 붙잡기(grasp and hold) → 물기 → 저항 시 추가 물기 → 섭식`. [T03]
- 10가지 먹이 유형을 제시한 실험에서 **톡토기류를 주로 포획**, 흰개미·귀뚜라미를 드물게 포획. [T03]
- 딱정벌레·개미·진딧물·총채벌레·파리·다른 거미·응애는 **그 실험에서 포획되지 않음**; 야외에서 절대 먹지 못한다는 뜻은 아니다. [T03]
- 먹이가 클수록 포획 효율 저하; 큰 톡토기에 **3회보다 많은 반복 물기**, 도약하는 먹이에 매달리는 행동도 보고. `toktogi` 고유 방어성능·포획률로 전용 금지. [T03]
- 수면 보행, 하루 이동거리, 주야 활동 비율, 먹이 탐지거리, 회피 성공률은 **미확인**.

## 5. 번식·발육·수명(2009 사육실험)
- **암컷 생산 단위생식(thelytoky)**: 단독 격리 개체가 교미 없이 살아 있는 자손을 생산했으며 연구 표본은 모두 암컷으로 성숙. [T04]
- **난낭:** 납작한 원반형, **난낭당 알 2개**. **개체당 평균 총 27알**은 성체 생애 동안의 합계이며 한 번의 산란량이 아니다. [T04]
- **fertility 약 59%**는 해당 연구의 생식 지표이며 야생 부화율·생존율과 동일하지 않다. [T04]
- **발육:** 성체 이전 **유체 3령**, 각 령 **대략 1개월**; **성체 기간 평균 약 6개월**, 전체 생애의 약 **54%**가 성체 단계였음. 전부 **사육 조건의 수치**다. [T04]
- 성체 나이에 따라 산란 속도 감소. 해당 실험에서 *Wolbachia*·*Cardinium*이 단위생식의 원인이라는 근거를 찾지 못했으나, 모든 개체군에서 영구 부재하다는 뜻은 아니다. [T04]
- 교미·수컷 구애, 야생 산란수·수명, 수온·습도별 생존·월동 능력은 **미확인**.

## 6. 먹이망·`toktogi`와의 관계
| 관계 | 판정 |
|---|---|
| 톡토기류 → *T. stenaspis* | **종 수준 직접 먹이 실험으로 확인** [T03] |
| `toktogi`(*S. aquaticus*) → *T. stenaspis* | **미확인**: 실험의 톡토기가 해당 종으로 동정되지 않음 |
| `toktogi` → 종 미상 거미 | **다른 자연사 사진에 포식 관찰 기록** [T09] |
| 자연 연못에서 두 종 공존·수면 포식 | **미확인**: 온실 낙엽 서식과 수면생활은 다른 조건 |
- 진딧물 방제 전용 천적으로 설정하지 않는다(해당 실험에서 진딧물 미포획). 포식자의 구체적인 천적 종명·포식률도 미확인. [T03]
- **생물안전:** 도입·정착력이 있는 온실 개체를 한국 자연 연못에 임의 방사하지 말 것. [T01][T08]

## 8. 관찰·검증 사항
- 몸길이·성체 여부·눈 6개·다리 가시·경화판을 촬영해 종 동정; 실험 먹이도 종/몸길이별로 동정.
- `조우→접근→붙잡기→물기 횟수→먹이 도약/탈출→섭식/방출`을 구분. 실패한 시도도 기록.
- 조건(온습도·기질·장소·관찰시각)을 기록하고 실험실 산란·수명 수치를 야외 고정값으로 쓰지 않는다.
- 외래 개체 방사 대신 기존 서식 표본·격리 시설·비침습적 관찰을 우선한다.
