# 학명 사용 (Pergamasus crassipes) — 3D 외형 모델 명세서

> **기준:** `toktogi_model.md`의 외형 명세 범위(실루엣·크기·외부 기관·색채·표면·미정 수치). **대상 분류:** 종.
> **범위 주의:** 토양성 중기문응애이며 거미는 아님. 속 사진에서 추정한 크기·가시·수컷 제2다리 특징을 “이 종 확정치”로 바꾸지 않는다.
> **톡토기 관계:** 다른 톡토기류 실험 포식 확인, 수면형 물알둥근톡토기 직접 포식 미확인.

## 1. 전체 형태

| 항목 | 3D 실루엣·구성 |
|---|---|
| 몸 윤곽 | 거미와 달리 명확한 머리가슴/배 허리 연결이 보이지 않는 작고 타원형 단일 덩이. |
| 몸 표면 | 등면 경화판과 가는 강모가 있는 주황~적갈색 소형 응애형. |
| 성체 다리 | 4쌍 8개; 유충은 일반적으로 3쌍으로 시작하는 응애류 생활사. |
| 머리 부속물 | 몸 앞쪽의 큰 협각/촉지(gathosoma), 곤충형 더듬이는 없음. |
| 날개·실젖 | 없음. 수면 활주나 거미의 8안 배치를 그대로 복제 금지. |
| 포즈 | 낙엽·토양 틈을 지나가는 낮고 촘촘한 보행 자세. |

## 2. 크기·성차·성장 단계

| 구분 | 값과 적용 범위 |
|---|---|
| 크기 | 약 **0.8–1.5mm**는 *Pergamasus* **속 사진의 추정값**이며 *P. crassipes*의 종별 실측값은 확보되지 않음. [A2] |
| 암컷·수컷 | 성별별 성체 길이·몸체 높이·폭은 미정. |
| 유체 | 알→유충→제1약충→제2약충→성체; 각 단계 크기/형태는 실측 없이 성체 축소 금지. |
| 측정 | body length는 두화부(gnathosoma)와 다리를 포함하는지 문헌별 정의 확인 필요. |

> **치수 해석:** 위 mm/cm는 자료의 **몸길이**이며, 부속지까지 포함한 전체 외접 크기와 다릅니다. 표본·단계·측정법을 보존합니다.

## 3. 부위별 외형

| 부위 | 모델링 요구 및 근거 범위 |
|---|---|
| 등판 | 타원형 방패 모양 경화판을 위쪽에, 표면 강모의 열을 정밀 LOD에. |
| 배판 | 복면 경화판과 생식개구부; 종 검색표 없이는 선·가시 개수 확정 금지. |
| 협각 | 먹이를 무는 한 쌍의 집게·턱 구조; 거미 독니나 노린재 주둥이와 다름. |
| 촉지 | 입 주변에 짧은 1쌍의 감각부속지, 더듬이로 오인 금지. |
| 다리 I | 첫 쌍은 앞으로 향해 더듬는 자세; 엄밀한 감각운동 비율 미정. |
| 다리 II | 일부 *Pergamasus* **수컷에서 제2다리 변형**. 이 종 표본으로 확인하기 전 별도 옵션으로만. [A2] |
| 다리 III·IV | 앞 2쌍보다 뒤에 부착되어 몸 아래 지지. |
| 발끝 | 작은 발톱 및 접착성 말단 구조는 종별 현미경 확인 필요. |
| 강모 | 등판·다리·복판 강모는 종 동정에 사용되므로 개수 임의 고정하지 않음. |
| 몸마디 | 가슴·배가 거미처럼 잘록한 두 덩이로 표현되지 않음. |

## 4. 색채·표면·재질

| 항목 | 재질·무늬 명세 |
|---|---|
| 체색 | 주황~붉은갈색 계열(속 사진); 본 종의 색상 표준값 미확정. |
| 경화판 | 어두운 등판과 주변 연한 몸막의 대비는 개체별로 확인. |
| 표면 | 단단한 판은 부드러운 몸막보다 매끈할 수 있으나 반사계수 미정. |
| 털 | 작고 가는 강모, 근접 LOD에서만 개수 표현. |
| 생체 효과 | 습한 토양의 물기/반사는 환경 표현이지 본 종의 몸이 물에서 생활한다는 증거 아님. |

**재질 수치:** RGB/HEX, IOR, 금속성·거칠기·투명도, 강모 밀도는 명시된 출처에 없으면 **미정**이며 미술적 기본값을 생물 실측값으로 취급하지 않습니다.

## 5. 현미경·동정용 세부 형질

| 세부 | 구현 조건·주의 |
|---|---|
| 다리 수 | 성체 8개, 유충 6개라는 응애류 일반 형태를 구분. |
| 수컷 II 다리 | 속 수준 경향을 이 종의 수컷에 고정 적용 금지. |
| 판/강모 배열 | 종별 검색표 없이 정확한 수·길이·각도 미정. |
| 협각 | 입 부분은 gnathosoma에 위치, 몸통 전체를 거미형 독니로 묘사하지 않음. |
| 토양 생활 | 수면용 발끝 패들/방수털을 종 특징으로 추가하지 않음. |

## 6. 필수 참조 시점·모델 변형

- [ ] 등면: 타원 경화판·강모 열
- [ ] 측면: 낮은 토양 보행 자세
- [ ] 정면: 협각·촉지와 첫째 다리
- [ ] 복면: 성별 판·생식부(정밀형)
- [ ] 유충 6다리/성체 8다리 대조

> 표본 사진·논문 도판은 **형태 검증용 링크**로 사용하고, 재배포 권리는 별도 확인합니다.

## 7. 메시·리깅/LOD 제안 (제작 규칙; 생물 실험값 아님)

| 하위 구성 | 권장 메시·본·상태 |
|---|---|
| idiosoma | 타원 몸체 루트. |
| gnathosoma | 앞쪽 입부를 별도 조인트. |
| chelicerae/palps | 작은 먹이 포획·촉지 움직임 분리. |
| legs_1..4 | 성체 8개 보행 리깅; 유체는 단계별 다리수 분기. |
| plates | 등/배 경화판을 독립 재질·노멀로. |
| LOD | 강모 밀도와 0.1mm 미만 미세 돌기는 근접 단계에서만. |
| animation | litter_walk, palpate, seize, feed 제안; 수면 이동 기본값 없음. |

## 8. 원 자료만으로 확정할 수 없는 값

- **미정:** 종 자체의 정확한 성체 크기·성별 차이.
- **미정:** 수컷 제2다리 변형의 확실한 종 수준 도판.
- **미정:** 강모 수·패턴·생식판의 정확한 형태.
- **미정:** 협각 크기와 먹이 포획 순간 동작.
- **미정:** 물알둥근톡토기와의 실제 미세서식지 접촉.
