# 물노린재 (*Mesovelia vittigera*) — 2DGP 생물 명세서

> **범위:** 한국 수면·부유식물에서 기록된 노린재 **종**. 과·속 수준의 작은 수생무척추동물 포식 근거는 있지만, *Sminthurides aquaticus*를 먹었다는 직접 자료는 **미확인**이다. [V01][V02]

## 1. 분류·이름·근거
- 동물계 → 절지동물문 → 곤충강 → 노린재목 → **물노린재과(Mesoveliidae)** → *Mesovelia* → ***M. vittigera* Horváth, 1895**. 국명 **물노린재**. [V01][V05]
- 과거 일부 기록에 ***M. orientalis***가 등장하지만 현재는 *M. vittigera*의 이명으로 처리한다. [V01][V05]
- 근거: `[종 분포·형태]` 한국 현장 표본 / `[속·과 생태]` 포식·산란·감각 / `[미확인]` 톡토기 종별 섭식.

## 2. 크기·외형·동정
| 요소 | 근거와 해석 |
|---|---|
| 몸길이 | **2.0–3.5 mm**(태국의 *M. vittigera* 문헌); 한국 전체 개체군 평균으로 전용 금지. [V03] |
| 체형 | 길쭉한 타원형 몸, 머리보다 긴 더듬이, 큰 겹눈, 길고 가는 다리. [V02] |
| 체색 | 산 개체에서 녹색빛이 도는 황록색~황갈색, 개체·날개형별 무늬 차이. [V01][V02] |
| 날개 | **무시형(apterous)**과 **장시형(macropterous)**이 존재; 2024년 한국 표본에 날개가 긴 수컷이 포함. [V01] |
| 입 | 소형 무척추동물에 사용하는 흡즙형 주둥이; 식물 섭식 전용 곤충으로 분류하지 않음. [V02] |
- 한국의 *M. thermalis*·*M. egorovi*와 혼동 가능: **암수의 복부 말단·수컷 제8복판** 등 현미경 형질로 동정. 과거 분포 기록은 재검토 대상이다. [V01]

## 3. 국내 분포·서식지
- **한국 직접 기록:** 2024년 5월 고양 일산호수공원 및 의왕 왕송저수지 표본, 6월 충남·경북·전남 등지 표본이 논문에 수록됐다. [V01]
- 한국에서는 **호수·저수지·논·기수 연못**의 부유식물·식생이 많은 구역을 이용했다. 특정 식물을 항상 필요로 한다는 뜻은 아니다. [V01]
- 동아시아 외에도 유럽·아프리카·호주 등에 널리 알려져 있고 동남아 일부 기수 환경에서도 발견됐다. [V03]
- 대상 톡토기는 잔잔한 수면·개구리밥을 이용하므로 **미세서식지가 겹칠 가능성**이 높지만 국내 같은 수역에서 종별 동시 출현은 미확인.

## 4. 이동·감각·포식 행동
- 수면에 걸친 잎·줄기에서 빠르게 걸으며 필요하면 수면을 건너는 **반수서성 포식자/청소동물**. [V02][V04]
- Mesoveliidae 안내에 따르면 물 표면 진동으로 먹이를 탐지하며 물벼룩류·패충류 등 작은 갑각류, 죽어가는 모기·깔따구 등을 먹는다. **과/속 생태**, 이 종 전용 식단 비율 아님. [V02]
- 작은 먹이에 주둥이를 대어 체액을 섭취; 사냥과 사체 청소를 구별해야 한다. [V02]
- **근연종 선행기록:** Hungerford(1917)는 Butler(1893)가 ***Mesovelia furcata***에 ***Smynthurus*** 톡토기를 먹이로 제공하고 섭식 장면을 보았다고 재인용했다. 살아 있는 먹이를 직접 잡았는지 사체를 먹었는지는 불명. 이는 ***M. vittigera*의 실험이 아니다**. [V07]
- 같은 1917년 연구의 ***M. mulsanti*** 어린 약충은 톡토기를 공격하다 수면에서 뒤집히는 경우가 관찰돼, 공격을 포식 성공으로 취급할 수 없다. [V07]
- 장시형은 비행할 수 있는 잠재력이 있지만, 모든 개체가 날 수 있는 것은 아님. [V02]
- `S. aquaticus` 전용 탐지거리·공격속도·먹이 선택성·포식률은 **자료 미확인**.

## 5. 생식·성장·생활사
- **속 수준**에서 수컷이 앞다리로 암컷을 붙잡아 교미하고, 암컷이 산란관으로 식물 조직에 각각 알을 넣는 행동이 기술돼 있다. [V04]
- 알 → 약충 → 성충의 불완전변태. 약충은 날개·생식기관이 성체와 다르다. [V02]
- 한국산 *M. vittigera*의 정확한 난수·산란시간·약충 령 수·발육 온도·성체 수명은 **확인할 종별 자료 부족**.
- *Mesovelia* 전반의 생활사를 이 종에 확정값으로 대입하지 않는다.

## 6. 먹이망·`toktogi` 관계
| 관계 | 판정 |
|---|---|
| 작은 수면 무척추동물 → *Mesovelia* spp. | **속·과 수준 포식/청소 근거 있음** [V02] |
| *Smynthurus* sp. → *M. furcata* | **1893년 섭식 기록의 1917년 재인용**; 산 먹이 포획 여부 미확인 [V07] |
| 물알둥근톡토기 → *M. vittigera* | **서식지 기반 후보(D), 직접 포식 미확인** |
| *Sminthurides bifidus*와 *Mesovelia* sp. | 개구리밥 위 동시 관찰 사례는 있으나, **양측 종 동정이 여기의 대상 종과 다름** [V06] |
| 한국 수면 조사 | *M. vittigera* 자체 출현 **확인**. 톡토기와 먹이 관계의 증거는 아님 [V01] |
- 이름이 비슷한 물벌레과(Corixidae)의 *Corixa punctata*와 **다른 과**에 속한다.

## 8. 검증 과제
- `M. vittigera`와 비슷한 한국종을 **암수 생식구조**로 확인하고, 톡토기도 종 동정.
- 같은 부유잎에서 `조우/공격/흡즙/사체 섭취/방출`을 분리 촬영하며 표본·날짜·시간을 기록.
- 종별 실제 포식 기록 없이 `predator_of_toktogi: confirmed`로 상향하지 않는다.
