# *Hydrometra martini* — 2DGP 생물 명세서

> **범위:** 실소금쟁이과(Hydrometridae)의 북미산 **종**. *Sminthurides malmgreni*를 먹이로 삼은 사육실험이 있으나, *S. aquaticus*에 대한 종별 포식은 미확인이다. [H01]

## 1. 분류·이름·근거
- 동물계 → 절지동물문 → 곤충강 → 노린재목 → 실소금쟁이과(Hydrometridae) → *Hydrometra* → ***H. martini* Kirkaldy**. [H01][H02]
- 국내에는 다른 *Hydrometra* 종(*H. albolineata*, *H. procera* 등)이 등재되어 있다. **이 북미 종이 한국에 분포한다는 근거는 확보하지 못했다.** [H04]
- `[종 표본]` 1981년 형태·분포 / `[종 사육실험]` 2000년 먹이·기질 / `[속 일반]` 실소금쟁이 형태 / `[미확인]` `toktogi` 직접 포식.

## 2. 크기·외형·동정
| 요소 | 관찰·문헌 근거 |
|---|---|
| 성체 수컷 | **7.7–8.5 mm**, 측정 표본 n=10; 지역 표본의 전체 몸길이(TL). [H02] |
| 성체 암컷 | **8.8–10.15 mm**, 측정 표본 n=10; 같은 문헌의 값. [H02] |
| 실루엣 | 기다란 바늘형 몸, **매우 긴 머리**와 전방으로 나온 더듬이, 길고 가느다란 여섯 다리. [H02][H03] |
| 색·눈 | 갈색~암갈색 계열; 눈이 머리의 앞쪽 끝이 아니라 **뒤쪽에 치우쳐 있음**. [H03] |
| 날개 | 축소된 날개형이 있으며 다른 날개형의 비율·비행능력은 표본군에 따라 확인해야 한다. [H01][H03] |
| 입 | 절지동물을 찔러 먹는 **흡즙형 주둥이**; 물가 노린재와 달리 매우 가늘고 긴 몸통. [H02][H03] |
- *H. australis*와의 외형 유사 및 과거 동의어 가능성 논의가 있어 **생식기·더듬이 형질과 최신 검색표를 함께 확인**한다. [H01][H02]

## 3. 서식·분포·활동
- 미국 일리노이 조사에서 **얕고 잔잔한 수면**, 부유식물·정수식물이 풍부한 호숫가에서 성충을 채집했다. [H01]
- 미네소타 조사에서는 수초 많은 연못·호수·개울 가장자리에서 기록되었고, 성충이 물가 식생에서 겨울을 나는 사례가 기술된다. [H02]
- 걷는 동안 길고 가는 다리를 이용해 물 표면 또는 물에 걸친 식물 위를 이동하며, 수면 근처 먹이 신호를 탐색한다. [H02][H03]
- 한국의 물알둥근톡토기 연못과 **실제 동시 출현 근거 없음**; 같은 속의 한국종으로 결과를 자동 전용하지 않는다.

## 4. 포식·일상 행동
- 2000년 실험에서 ***Sminthurides malmgreni* 또는 초파리 *Drosophila melanogaster***를 먹이로 제공하여 성장단계별 생존·발육을 분석했다. [H01]
- **먹이와 기질의 상호작용:** 젖은 여과지에서는 *Sminthurides* 먹이가, 개구리밥 덮인 수면에서는 초파리 먹이가 더 유리한 조건으로 요약된다. [H01]
- 종속 변인이 생존율·각 령의 기간이었으므로 '톡토기를 무조건 선호한다'거나 야생에서 톡토기가 주식이라는 결론은 부적절하다.
- 일반적인 포획 흐름은 `먹이 탐지 → 접근 → 주둥이 찌르기 → 흡즙`; 정확한 접근속도·성공률은 대상 종 수준에서 미확인. [H02][H03]
- 실험에서는 약충에게 **살아 있는 *S. malmgreni* 약 20마리/처리용기/일**을 유지하도록 공급했다. 이는 **실제 포식량이 아니라 제공량**이다. [H01]
- 같은 개구리밥 사육용기에서는 **갓 우화했거나 우화 중인 깔따구 성충**도 먹는 행동이 관찰됐다(톡토기 전문식성으로 오해 금지). [H01]
- 덫그물은 만들지 않고 외부에서 온 물체를 먹이로 인식·취급하는 경우가 있다. 하루 먹이량·먹이 탐지거리는 확정치 없음.

## 5. 번식·발육·수명
- 식물·수면 위로 나온 지지물에 알을 붙이며, **약충이 성체와 유사한 불완전변태**를 한다. [H01][H03]
- 2000년 사육실험은 **28 ± 1°C, 12시간 명기/12시간 암기**에서 알과 약충을 길렀다. 해당 생존·발육 결과는 이 조건에 한정한다. [H01]
- 개구리밥 처리에는 *Lemna minor*, *Spirodela polyrhiza*, *Wolffia papulifera*가 사용됐다. 이들의 '동일 기질'은 토착 자연 연못의 동시 출현과 다르다. [H01]
- 북미 연구에서 성충 월동이 기록됐으나 월동 시기·생존율은 지역마다 다를 수 있다. [H02]
- 알 수, 종별 부화 일수, 포획 가능 연령, 최대수명·연간 세대수의 전 지역 공통값은 미확인.

## 6. 먹이망·`toktogi`와의 관계
| 연결 | 판정 |
|---|---|
| *S. malmgreni* → *H. martini* | **직접 종 실험:** 먹이로 사용하여 발육·생존 평가 [H01] |
| 초파리 → *H. martini* | **직접 종 실험:** 비교 먹이 처리 [H01] |
| *S. aquaticus* → *H. martini* | **미확인:** 먹이 종을 바꿔 적거나 지리적으로 동시 출현 가정 불가 |
| 한국 *Hydrometra* spp. → 톡토기 | **연구 후보:** 속을 공유하지만 위 실험의 종과 같지 않음 |
- *H. martini*를 한국에서 발견된 거미나 물노린재의 정식 천적으로 취급하지 않는다.

## 8. 검증 과제
- 입·더듬이·생식기 등 형태를 비교해 **유사한 *Hydrometra* 종을 구분**; 한국 종은 별도 객체로 제작.
- *S. aquaticus* 실험을 한다면 **톡토기 종 동정·식물 피복·기질·수온·발육령**을 통제해 기록.
- `먹이 부여 → 접근 → 흡즙 → 생존/성장`을 개별 변수로 구분하고, 실험 조건의 먹이 효과를 자연 상태의 선호도로 환산하지 않는다.
