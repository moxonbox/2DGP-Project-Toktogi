# 실소금쟁이류 (학명 사용) (Hydrometra stagnorum) — 3D 외형 모델 명세서

> **기준:** `toktogi_model.md`의 외형 명세 범위(실루엣·크기·외부 기관·색채·표면·미정 수치). **대상 분류:** 종.
> **범위 주의:** 유럽산 종의 형태 명세. 국내 수면 포식자로 자동 배치하지 않으며 장·단시형과 성별 형태를 구분한다.
> **톡토기 관계:** *S. aquaticus* 섭식 사진 캡션 보고 있으나 독립 양측 종 동정 미확인.

## 1. 전체 형태

| 항목 | 3D 실루엣·구성 |
|---|---|
| 전체 체형 | 매우 길고 가느다란 막대형 몸; 노린재 중에서도 수면을 재듯 천천히 걷는 실루엣. |
| 머리 | 특히 길고 좁은 머리, 양 옆 눈은 머리 뒤쪽에 치우침. |
| 다리 | 다리 3쌍·6개, 길고 가늘며 발끝이 물에 닿는 자세. |
| 더듬이 | 머리 전방으로 나오는 가는 1쌍; 두 갈래 더듬이를 뿔로 과장하지 않음. |
| 날개형 | 짧은 날개형이 흔하고 장시형이 드물게 보고됨. |
| 주둥이 | 머리 아래로 접히는 가는 찌르기·흡즙형 주둥이. |

## 2. 크기·성차·성장 단계

| 구분 | 값과 적용 범위 |
|---|---|
| 성체 | 독일 종 자료 **9–12.5mm**; 영국 안내 약 **9–13mm** (몸길이). [H1][H2] |
| 암수 | 독립된 암수 체장 범위·몸 비율 이번 자료 미확정. |
| 날개 | 날개형별 크기·비행능력은 지역 개체군 자료 필요. |
| 측정 | 안테나·다리 외접길이를 몸길이에 더하지 않음. |

> **치수 해석:** 위 mm/cm는 자료의 **몸길이**이며, 부속지까지 포함한 전체 외접 크기와 다릅니다. 표본·단계·측정법을 보존합니다.

## 3. 부위별 외형

| 부위 | 모델링 요구 및 근거 범위 |
|---|---|
| 머리 | 길쭉한 앞머리; 눈 **앞부분**이 눈 뒤쪽 길이보다 약 2배인 동정 기준이 종 소개 자료에 제시됨. [H1] |
| 겹눈 | 머리 양쪽에 돌출되지만 머리 끝에는 위치하지 않음. |
| 더듬이 | 마디가 나뉜 한 쌍, 평면 개념 모델에서 앞으로 넓게 편 자세. |
| 주둥이 | rostrum을 아래쪽에 별도 관절로 만들어 접근→찌르기 동작. |
| 앞가슴등판 | 가늘고 긴 몸 앞쪽, 머리와 배의 경계를 흐리지 않음. |
| 가슴·배 | 폭이 좁고 긴 흉부/배부; 겹침 날개형이면 접힌 날개가 등면에 놓임. |
| 다리 | 보행다리 6개가 몸 앞/중/뒤에서 시작; 작은 관절과 접지용 말단. |
| 발 끝 | 수면에서 접촉점은 6개 다리 끝과 물표면의 별도 효과로 표현. |
| 복부 말단 | 성별·종 동정용 말단 생식구조는 고배율 모델 전용. |
| 알(선택) | 표면 지지물에 하나씩 부착한 길쭉한 알. 2024년 연구 표본은 길이 약 0.869–1.10mm. [H3] |

## 4. 색채·표면·재질

| 항목 | 재질·무늬 명세 |
|---|---|
| 체색 | 회갈색~흑갈색 계열; 등면에 연한 종방향 선이 나타나기도 함. |
| 눈 | 몸보다 진한 겹눈. 한 몸 전체에 두꺼운 줄무늬를 추가하지 않음. |
| 다리 | 가늘며 관절부 색조 차이 가능; 정확한 색 패턴 미정. |
| 표면 | 경질 외골격의 약한 광택·작은 강모, 물 표면 거울반사는 환경 머티리얼. |
| 날개 | 짧은 형태와 긴 형태를 별도 메쉬, 모두 같은 투명 날개로 표현하지 않음. |

**재질 수치:** RGB/HEX, IOR, 금속성·거칠기·투명도, 강모 밀도는 명시된 출처에 없으면 **미정**이며 미술적 기본값을 생물 실측값으로 취급하지 않습니다.

## 5. 현미경·동정용 세부 형질

| 세부 | 구현 조건·주의 |
|---|---|
| 머리 비율 | 눈 앞머리/눈 뒤머리의 **비율**은 유사종 비교 특성; 전체 몸 길이의 2배라는 뜻 아님. |
| 성별 | 복부 말단·수컷/암컷 생식구조는 선택 종 표본으로 확인. |
| 날개 다형 | 단시형 모델의 날개를 성충에게 완전히 제거하는 무시형과 혼동 금지. |
| 주둥이 위치 | 두꺼운 모기 흡혈관을 앞쪽으로 길게 뻗은 모습은 잘못됨. |
| 동정 범위 | *H. gracilenta* 등 유사종의 머리/날개형을 조합해 혼성 모델 금지. |

## 6. 필수 참조 시점·모델 변형

- [ ] 등면: 머리·흉부·배 길이 분절
- [ ] 측면: 수면에서의 높이·주둥이 접힌 위치
- [ ] 정면: 눈 위치·더듬이 기부
- [ ] 두 날개형 등면 비교
- [ ] 물가 식물에 알 부착한 성체(선택)

> 표본 사진·논문 도판은 **형태 검증용 링크**로 사용하고, 재배포 권리는 별도 확인합니다.

## 7. 메시·리깅/LOD 제안 (제작 규칙; 생물 실험값 아님)

| 하위 구성 | 권장 메시·본·상태 |
|---|---|
| head/thorax/abdomen | 긴 축의 3 덩이로 나누되 매끄러운 몸 표면 유지. |
| leg_pairs_1..3 | 6개 긴 보행다리의 관절과 수면 접지 제어. |
| antennae | 머리 전방 1쌍을 좌우 독립 회전. |
| rostrum | 먹이 흡즙 시에만 아래에서 펴는 별도 본. |
| wings | short_wing / long_wing morph 스왑. |
| surface_fx | 수면 변형/장력 자국은 몸이 아닌 환경 효과; 실제 물리 수치 미정. |
| LOD | 먼 거리에서 머리 비율을 보존하고 강모/눈 미세부는 근접 LOD로. |

## 8. 원 자료만으로 확정할 수 없는 값

- **미정:** 암수별 체폭·높이와 다리 편길이.
- **미정:** 다리·더듬이 마디 길이와 접지 각도.
- **미정:** 날개형/개체군별 비율·비행 능력.
- **미정:** 주둥이 길이와 실제 흡즙 시 접힘 각도.
- **미정:** 국내 자연 개체군 분포 및 특정 톡토기 섭식 동정.
