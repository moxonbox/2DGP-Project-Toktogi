# framework-r4 변경 및 검증

- Q와 방향키 반전은 같은 발 지지 검사로 진입한다. 가장자리에서 발판 안쪽 이동은 유지하며, 지지를 확보한 뒤 회전한다.
- F 해제 후 이동은 현재 셀을 거쳐 보행·반전으로 이어진다. F 재입력과 G도 직전 섭식 셀에서 연결한다. X의 공격 판정 시각은 유지한다.
- 시작점과 체크포인트의 Capsule이 다른 발판과 겹치면 코스를 거절한다.
- Q의 중립 반전은 480ms를 유지하며 두 지지 자세에 각각 100ms를 배정한다. Z의 보정과 저장 Action 검증은 Blender 폴더를 참조한다.
- HTML은 번들 버전을 읽는다. 대표 리플레이 4개의 물리 틱 기록도 내장한다. 명세 v2.1의 시험별 확인 범위는 REQUIREMENT_VERIFICATION.md에 기록했다.

# framework-r3 변경 및 검증

- Z는 지지점이 전체 디딤 구간에서 도달 가능하도록 계산하고 5ms마다 본 키를 굽는다. 인접 키의 쿼터니언 부호를 맞췄다. 1.55초, 좌우 62셀과 양끝 공유 자세를 유지했다.
- F 복귀 동안 자동 균형 보행을 기다린다. 직접 이동 입력은 즉시 물리에 반영한다. P와 F2는 섭식 효과를 바로 닫고 표시 복귀를 보존한다. X는 같은 틱에 시작하며, 기존 타격 창 전에 최대 75ms의 표시 연결을 사용한다.
- 공격 핵심 셀과 공중제비의 진입·역위·복귀를 10fps의 모든 표시 시작 위상에서 확인했다. F2·HTML에 동일한 게임 입력으로 만든 4개 리플레이를 제공한다.
- 공통 번들은 PNG 헤더·크기·참조를, 플레이 정책은 필수 모션과 최소 셀 수를 검사한다. 코스 시작과 체크포인트의 자세 여유를 검사한다. `Assets`는 선택한 보조 ZIP과 인스턴스별 맵 캐시를 지원한다.

저장 Action의 좌우 1,954자세를 2.5ms 간격으로 재검사했다. 왼쪽에서 다른 다리끼리 교차하는 삼각형 쌍은 r2 대비 출력 키 1,883→308, 5ms 사이 자세 11,060→2004이었다. 연속 평가의 지지발 높이 최대값은 0.265px다. 세부 결과는 `spin_interkey_validation.json`에 있다.

수면·산란 제외. Computer-Use 미사용.

# framework-r2 변경 및 검증

- F를 떼면 현재 셀부터 복귀한다. 새 E/F/G/X는 섭식 복귀가 끝나기 전에 수락할 수 있다. 작업 가능색은 실제 수락의 지지발 검사와 같은 기준을 사용한다.
- Capsule 수평 충돌은 가장 가까운 경계를 사용한다. Course, Track, FixedStepTimeline 생성자와 번들의 필수 클립·프로필·표본·마커·PNG 참조를 검증한다.
- 게임 재생 시간은 motion.py에서 관리한다. F2와 HTML에 양방향 Z·공중제비·일반/탄성 전개 8개를 실제 게임 시간으로 추가했다.
- Z는 좌우 각각 120Hz에서 62자세·1.55초다. 중간 60자세는 12개 지지 구간이다. Q는 현재 대기 셀에서 중립 자세를 거쳐 반전으로 들어간다. 공중제비는 330ms이며 중심 역위 자세를 105ms 표시한다.

`python main.py --verify`에서 기존 62그룹과 이번 5그룹을 검증한다. Blender에 저장한 자세와 출력 셀의 해시 근거는 `blender/framework-r2`에 있다. Computer-Use 미사용. 수면·산란 제외.

# framework-r1 변경 및 검증

입력 정렬, 순수 Capsule 충돌, 코스 설정, 모션 선택, PNG 저장소와 셰이더, 플레이·검수 장면을 분리했다. 단위별 진입점과 호출 순서는 ../document/markdown/021_toktogi_game_framework_spec.md에 있다. 기존 55개 회귀를 구조 변경 전후에 실행했다.

Z는 양쪽에서 안정된 접지 대기 또는 보행에 연결된다. 대기 중 현재 표본에서 중립으로 이어지며 보행은 위상별 제동을 거친다. 본 회전은 62자세·1.55초이고 같은 논리 방향으로 완료한다. 공중·가장자리의 부적격 입력을 막았다. 회전 중 요청한 공격·작업·점프는 종료 경계와 취소 규칙을 적용한다. 좌우의 10·15·30·60fps 시작 위상에서 4개 방향 구간이 모두 표시됐다.

재질 스프라이트 셰이더는 공용 5패스 제공자를 입력으로 받는다. 게임에서 상단 추적광의 가로 방향은 코스 진행에 따라 변한다. 같은 표본에서 2,243개 RGBA 픽셀의 RGB가 바뀌고 Alpha는 일치했다. 기존 24개 조명 기준 출력의 오차 한도는 채널당 1/255다.
