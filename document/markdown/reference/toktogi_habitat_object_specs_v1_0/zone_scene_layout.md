# 서식 구역·장면 프리셋 구성 규칙 (독립 에셋 제외)
> 원본 `toktogi_habitat.md`의 6개 Z구역/3개 장면을 인스턴스 조합으로 재현한다. 구역에는 독립 게임용 생물 `model`·`movement` 문서를 부여하지 않고 구성 에셋 문서에 재사용한다.

## 구역 배치
| 구역 | 실제 근거/한계 | 접점·충돌 조합 |
|---|---|---|
| Z0 | 톡토기 수면 보행·도약 A | 수면 collision + 외부 부유식물 앵커 + 국소 조류 |
| Z1 | L. minor 산란 A, 다른 식물은 B/C | 물선과 엽상체 상면·뿌리 수중 구분; B 식물은 비상호작용 |
| Z2 | 젖은 나무·돌 이용 A | 고형발판 상면과 수면 접합, 젖음 마스크 |
| Z3 | 수변 일반 환경 B/C | 물선과 진흙·모래·자갈 경사의 충돌 연속성 |
| Z4 | 물가 식생 B/C | 고마리·부들·갈대 뿌리 기부가 젖은 지면에 연결 |
| Z5 | 수중 환경 B/C; 톡토기 상시 잠수 근거 없음 | 뿌리/수중 잎, 퇴적층, 미세 표현은 비주요 접촉면 |

## 장면 프리셋
| 프리셋 | 필수 에셋 | 금지된 추론 |
|---|---|---|
| POND_CORE | 수면 + L. minor + 조류 패치 + 부유 나무 | 다른 부유식물에 산란 습관 전용 금지 |
| WATER_EDGE | 수면 + 경사 + 젖은 돌 + 수변 식생 | 장기 육상 정착 확정 금지 |
| KOREAN_SHORE_OPTION | L. perpusilla 또는 Spirodela + 부들·갈대·고마리 + 붕어마름 | 한 장소에서 모든 종 동시 출현 가정 금지 |

## 연동 상태 머신
1. `water_level`은 `env_still_water` 물리 시스템 소유; 수위 이벤트를 경사·나무·돌·식물의 `wetness_mask`에 배포.
2. `float_root`는 부유 자산별 물리 앵커; 시각 bob은 개별 visual_root에서만 수행.
3. `contact_surface`가 A 자산일 때에만 톡토기 보행/착지 AI 후보로 지정; B 자산은 비상호작용.
4. `oviposit_on`은 L. minor만 A 증거; `feed_on`은 조류 섭식만 A 증거, 수치화는 미확인.
5. `surface_to_shore`는 접촉 경계 끊김·수위 변화·LOD 시나리오로 테스트.
6. `3Dconv2D` 파이프라인과 DEC-06 최종 시점·회전·Normal 계약은 보류; 프로토타입 수치를 양산으로 승격 금지.

## 미결정
- 수류/파동/습윤 한계, 토양 마찰, 토양 경사, 바람·재생·부유 속도, 지역 출현 빈도는 원문에서 확정하지 않음.
