# 얼룩깨알소금쟁이 (Microvelia reticulata) — 3D 외형 모델 명세서

> **기준:** `toktogi_model.md`의 외형 명세 범위(실루엣·크기·외부 기관·색채·표면·미정 수치). **대상 분류:** 종.
> **범위 주의:** 성체 무시형(날개 없음)과 장시형을 반드시 분리한다. 무시형 성체는 약충과 동일한 외형이 아니다.
> **톡토기 관계:** 수면 톡토기류 섭식 행동 기재, *S. aquaticus*라는 먹이 종 동정은 없음.

## 1. 전체 형태

| 항목 | 3D 실루엣·구성 |
|---|---|
| 몸통 | 둥글고 납작한 타원형의 매우 작은 노린재; 길고 가는 물위 보행다리. |
| 체형 | 머리–앞가슴등판–중가슴등판–배가 나뉘며 작지만 폭이 비교적 넓음. |
| 다리 | 성충 다리 3쌍·총 6개. 표면 접지용 작은 발끝. |
| 더듬이 | 한 쌍의 분절 더듬이가 머리 앞 양측에서 뻗음. |
| 날개형 | 날개 없는 성충형이 흔하고 완전날개형은 드묾; 다른 등판 실루엣. |
| 입 | 머리 아랫부분에 접히는 흡즙형 rostrum. |

## 2. 크기·성차·성장 단계

| 구분 | 값과 적용 범위 |
|---|---|
| 무시형 성체 | **1.4–1.6mm**: 영국·아일랜드 종 카드 기준. [V1] |
| 장시형 성체 | **1.6–1.9mm**: 같은 출처의 날개형 기준. [V1] |
| 암수 | 별도 암수 표준 길이·배 비율은 미확인. |
| 약충 | 성충보다 작고 날개·생식기관이 미성숙; 자세한 령별 비율 미정. |

> **치수 해석:** 위 mm/cm는 자료의 **몸길이**이며, 부속지까지 포함한 전체 외접 크기와 다릅니다. 표본·단계·측정법을 보존합니다.

## 3. 부위별 외형

| 부위 | 모델링 요구 및 근거 범위 |
|---|---|
| 머리 | 짧은 둥근 머리·옆으로 돌출된 겹눈. |
| 더듬이 | 연결마디가 보이는 1쌍; 몸길이와 비율은 원표 미정. |
| 주둥이 | 소형 톡토기 등에 찔러 체액 섭식할 수 있는 관통형 입. |
| 앞가슴 | 앞부분에 **끊긴 갈색 띠**; 유사종 *M. buenoi*는 연결된 띠라고 비교됨. [V1] |
| 중가슴 | 무시형 등면에서 분리된 중가슴등판이 보임. |
| 뒷가슴 | 무시형에서는 일부 가장자리에만 보이는 부분이 있음. [V1] |
| 배 | 작은 타원형 배; 양옆 테두리 및 몸의 미세 털. |
| 다리 | 3쌍·6개, 물 위 걷기용 길고 가는 분절 다리. |
| 장시형 날개 | 흰빛 무늬 중 중앙의 구부러진 갈고리형 패턴이 종 카드에 기재. [V1] |
| 발끝 | 수면 접촉용 작은 말단. 실제 발톱 위치/털 밀도는 미정. |

## 4. 색채·표면·재질

| 항목 | 재질·무늬 명세 |
|---|---|
| 몸 | 짙은 갈색~검정의 대비가 작은 체색. |
| 앞가슴 띠 | 옅은 황색을 임의 넣지 말고 원자료의 **갈색 끊긴 띠**와 등면 대비를 표본사진으로 판별. |
| 미세털 | 은빛 방수성 미세 털이 수면 접촉 및 물 젖음에 관련. |
| 다리 | 갈색 위에 일부 옅은 기부 마디; 종·광원에 따른 변이. |
| 날개 | 장시형 날개 무늬와 날개 없는 형의 등판을 별도 머티리얼/메쉬. |

**재질 수치:** RGB/HEX, IOR, 금속성·거칠기·투명도, 강모 밀도는 명시된 출처에 없으면 **미정**이며 미술적 기본값을 생물 실측값으로 취급하지 않습니다.

## 5. 현미경·동정용 세부 형질

| 세부 | 구현 조건·주의 |
|---|---|
| 날개형 비교 | 무시형의 중가슴등판/뒷가슴등판 노출구조가 핵심 동정 단서. |
| 앞가슴 무늬 | *M. pygmaea*도 띠가 끊길 수 있으므로 띠 하나로 단정 금지. |
| 날개 무늬 | 장시형의 흰색 갈고리형 무늬는 무시형에 적용하지 않음. |
| 다리 형태 | 짧은 몸과 대비되는 부속지 길이를 세부 비율 없이 극단적으로 늘리지 않음. |
| 동정 | 수컷 생식부와 등판의 겹침을 검색표로 확인할 것. |

## 6. 필수 참조 시점·모델 변형

- [ ] 등면: 무시형의 앞/중/뒷가슴 노출
- [ ] 장시형 등면: 흰빛 갈고리형 날개무늬
- [ ] 정면: 머리·겹눈·더듬이
- [ ] 측면: 수면 보행 자세
- [ ] 수면 방수털 클로즈업(근접 LOD)

> 표본 사진·논문 도판은 **형태 검증용 링크**로 사용하고, 재배포 권리는 별도 확인합니다.

## 7. 메시·리깅/LOD 제안 (제작 규칙; 생물 실험값 아님)

| 하위 구성 | 권장 메시·본·상태 |
|---|---|
| body | 머리/흉부/배부 분리. |
| legs_6 | 다리 3쌍 각각 관절과 접지 타겟. |
| antennae | 한 쌍 별도 회전 본. |
| rostrum | 접히는 주둥이를 먹이 접촉/섭식용 본으로. |
| wing_morph | apterous ↔ macropterous를 독립 형상 스왑, 그냥 날개 visibility 토글 금지. |
| surface_fx | 수면 함몰/동심원은 별도 효과, 몸색과 혼동하지 않음. |
| LOD | 거의 1.5mm형이므로 원경에서 띠/날개형 실루엣 유지. |

## 8. 원 자료만으로 확정할 수 없는 값

- **미정:** 암수별 체장·측면 두께.
- **미정:** 다리·더듬이·발톱의 실제 길이비.
- **미정:** 수컷 생식기 형태와 무시형 비율.
- **미정:** 은빛 미세털 길이/밀도.
- **미정:** *S. aquaticus* 섭식 여부·정량 사냥 행동.
