# 딱부리반날개속 (*Stenus*) — 2DGP 생물 명세서

> **범위:** 반날개과(Staphylinidae) **속** 객체. 톡토기 포식이 종별 실험으로 확립되어 있지만, 그 실험에 사용된 먹이는 *Sminthurides aquaticus*로 확인되지 않았다. [S01][S02]

## 1. 분류·근거
- 동물계 → 절지동물문 → 곤충강 → 딱정벌레목 → 반날개과(Staphylinidae) → 딱부리반날개아과(Steninae) → ***Stenus* Latreille, 1797**. [S04]
- 2015년 한국 연구에서 8종의 한국산 기록을 정리했고, 한국딱부리반날개 *S. koreanus*도 포함한다. 이 속 전체가 한 종의 크기·생태를 공유하지는 않는다. [S04]
- 근거 태그: `[속·종 실험]` 포식 장치 / `[국내 종 기록]` 한국 분포 / `[속 일반]` 화학방어 / `[미확인]` 수면 톡토기 종별 포식.

## 2. 크기·외형·감각
| 요소 | 확인된 내용·범위 |
|---|---|
| 크기 사례 | 한국산 ***S. koreanus* 3.2–3.3 mm**(국내 2015년 표본). **속 전체의 평균 크기 아님**. [S04] |
| 체형 | 가느다란 몸통, 짧은 앞날개(딱지날개), 드러난 유연한 배, 여섯 다리. [S03][S05] |
| 눈 | 머리 양측의 커다란 겹눈; 종별로 눈 형태·운동성·사냥 전략이 다름. [S01][S06] |
| 포획기관 | 길게 내밀 수 있는 **아랫입술(labium)** 끝에 끈적한 포획 패드가 발달. [S01][S04] |
| 방어기관 | 배 끝 **항문끝샘(pygidial gland)**에서 방어성 분비물을 방출하는 종들이 있음. [S05] |
- 종 동정은 몸길이·점각·가시·복부 구조·성숙 수컷 생식기를 함께 사용하며 큰 눈만으로 *Stenus* 종 확정 금지.

## 3. 서식·이동·일상
- 많은 종이 **호숫가·강가·젖은 토양·낙엽·식생**에 분포; 일부는 더 건조한 지표면에서도 발견된다. [S03][S04]
- *S. comma*처럼 빠르게 달리며 추적하는 종과, 식생·잔해 안에서 대기·기습하는 종을 구분해야 한다. [S06]
- **수면 스키밍(skimming):** 일부 종은 배 끝 분비물의 표면 확산을 이용해 물 위에서 빠르게 이동한다. 속 전체·모든 개체의 상시 이동법이 아니다. [S03][S05]
- 관찰 가능한 행동: `탐색 → 시각/접촉 방향전환 → 접근 → 아랫입술 사출 또는 위턱 공격 → 먹이 제압 → 섭식/이탈`.

## 4. 톡토기 포획·식성
- Betz (1998)는 여러 *Stenus* 종의 **표준화된 톡토기 포획 실험**에서 아랫입술이 위턱보다 효과적인 종들이 많음을 보였다. 종별 운동성과 의존도는 달랐다. [S01]
- ***S. comma* 실험**에서는 세 종류 톡토기를 제시했고, 공격의 약 절반에서 사출형 아랫입술을 사용했다. **크거나 비늘·강모가 많은 톡토기는 패드에서 떨어지기 쉬웠다.** [S02]
- 일부 종은 작은 유연한 무척추동물을 포식하며, 특정 톡토기만을 전용 먹이로 고정할 근거는 없다. [S03]
- 포식자 자신의 화학방어가 톡토기에 대한 공격 성공을 뜻하지 않는다. 흡즙형 물노린재와 사냥 기작도 다르다.

## 5. 번식·발육·수명
- 일반적인 딱정벌레 **완전변태**: 알 → 유충 → 번데기 → 성충. 유충도 작은 무척추동물의 포식자일 수 있다. [S03]
- 암수 교미·산란 후 유충이 발육하여 번데기가 되며, 일부 *Stenus* 종의 유충은 고치를 만들어 번데기가 된다. [S03]
- 교미 신호·난수·탈피 횟수·부화·성숙 기간은 **종마다 다르며 이 속 공통의 정량치 미확인**.
- 알주머니를 운반하는 거미와 달리, 늑대거미식 모성 행동을 복제하지 않는다.

## 6. `toktogi` 관계
| 연결 | 판정 |
|---|---|
| 다양한 톡토기류 → *Stenus* 여러 종 | **직접 포획 실험으로 확인** [S01] |
| 세 톡토기 종 → *S. comma* | **종 수준 실험 확인**(먹이 세 종의 동정은 원문 재검증) [S02] |
| *S. aquaticus* → *Stenus* spp. | **미확인:** 물알둥근톡토기를 먹이로 쓴 실험·사진을 확보하지 못함 |
| 한국 연못 주변 *Stenus* | 국내 분포는 확인, **톡토기와 같은 미세서식지·시간 동시출현은 미확인** |
- *S. aquaticus*의 도약 대응능력 또는 회피률을 다른 톡토기의 사냥 실험에서 역산하지 않는다.

## 8. 현장 검증 과제
- 한국에서 발견한 개체는 **속만 우선 동정**하고 가능한 경우 성충 생식기·미세형질로 종 동정.
- 사냥 도구(`labium`/`mandibles`), 먹이의 몸길이·강모·도약 유무를 분리 기록.
- 물가 지표·식생·물 위를 구별해 포식·실패·방출을 촬영; 상호작용 없는 동시 출현을 먹이 관계로 기재하지 않음.
