# *Pergamasus crassipes* — 2DGP 생물 명세서

> **범위:** 거미목이 아닌 **응애류(Acari, Parasitidae)**의 토양 포식자 **종**. 톡토기류 섭식 연구는 있지만 물알둥근톡토기의 **수면 생활권에 존재하거나 이 종을 먹는다는 근거는 없다**. [P01]

## 1. 분류·근거
- 동물계 → 절지동물문 → 거미강 → 응애류(Acari) → 중기문목(Mesostigmata) → 기생응애과(Parasitidae) → ***Pergamasus crassipes***. [P01]
- **거미(Araneae)가 아님**. 거미처럼 성체 다리 8개를 가진 거미강 동물이지만 포식·번식 구조는 다르다.
- 근거: `[종 사육실험]` 톡토기 섭식·발육 / `[속 형태]` 약 1mm급 크기·수컷 제2다리 / `[미확인]` 물 표면 출현·대상 종 포식.

## 2. 크기·외형·동정
| 요소 | 출처와 해석 |
|---|---|
| 몸길이 | ***Pergamasus* 속 사진·설명**은 대략 **0.8–1.5 mm**; **이 종의 성별별 확정 범위는 미확인**. [P02] |
| 색·형태 | 주황~적갈색의 타원·배 모양 몸, 등판 경화구조와 다수 강모. [P02] |
| 다리 | 성체 8개; **수컷 제2다리**가 두꺼워지고 집게처럼 변형되는 종들이 있음. [P02] |
| 입기관 | 작은 절지동물을 물고 파쇄하는 **협각(chelicerae)**; 노린재형 빨대 주둥이나 거미줄은 없음. [P01][P02] |
| 종 구별 | 몸의 판·강모 배열, 악판·생식부·수컷 다리 II 등 **현미경 형질** 필요. 속 사진만으로 종 확정 금지. [P01][P02] |

## 3. 서식·이동·습성
- **낙엽층·숲 토양** 틈에서 다른 미소절지동물을 찾는 지표/표토 포식성 응애. [P01][P02]
- 1962년 연구의 표본은 **뉴욕 Tully Forest의 토양**에서 채집됐다. 이 표본군의 출현이 전세계 분포 또는 한국 자생을 뜻하지 않는다. [P01]
- 몸과 다리의 감각기관으로 지표 틈을 탐색하며, 수면 보행·잠수·식물 위 장거리 이동 능력의 종별 자료는 없다.
- 다른 토양 톡토기와의 포식 관계를 `toktogi`의 연못 수면으로 직접 이동시켜선 안 된다.

## 4. 먹이·포식 행동
- Hartenstein (1962)의 ***P. crassipes* 및 *Amblygamasus septentrionalis*** 생활사 실험에서 **톡토기류·갑옷응애류·진딧물류**를 주된 먹이로 기록했다. [P01]
- 같은 연구는 더 적은 빈도로 다른 중기문응애와 거미류도 먹는다고 기술한다. **두 응애 종의 공통 경향**이며 먹이별 정량 비율은 초록에서 분리되지 않았다. [P01]
- 사냥 흐름(설계용): `토양 틈 탐색 → 먹이 접근/접촉 → 협각 포획 → 섭식`; 실제 *S. aquaticus* 대상 실험 행동은 미확인.
- **개체별 탐지거리·달리기 속도·일일 톡토기 포식량·물가 출현**을 임의 수치로 정하지 않는다.

## 5. 산란·성장·번식
- **알은 한 개씩 산란**. 연구 조건에서는 교미하지 않고도 알을 낳을 수 있었으나, 모든 야외 개체군의 의무적 단위생식으로 표현해서는 안 된다. [P01]
- 사육실험 **20°C, 상대습도 약 90%**에서 알은 **24–36시간**에 부화했다. 해당 조건의 관찰값이다. [P01]
- 유충 약 2일 후 **제1약충(protonymph)**, 그 뒤 약 1주일 후 **제2약충(deutonymph)**, **산란 후 약 3주에 성체**가 된다고 기술됐다. [P01]
- 연구진의 **야외 연 4~5세대 추정**은 시험지의 추정치이며 지구 전역이나 한국 연못의 고정 세대수 아님. [P01]
- 평균 암컷 총산란수·성별 수명·야외 온습도 최적치·먹이별 발육 차이는 종 수준 원표 재검토 필요.

## 6. 먹이망·`toktogi`와의 관계
| 연결 | 판정 |
|---|---|
| 육상 톡토기류 → *P. crassipes* | **종을 포함한 생활사 실험에서 포식 확인** [P01] |
| 진딧물류·갑옷응애류 → *P. crassipes* | **실험 먹이군 확인**(두 응애 종 자료의 합성 범위) [P01] |
| *S. aquaticus* → *P. crassipes* | **미확인:** 먹이 종·서식 미세공간 모두 불일치 가능 |
| 연못 수면·개구리밥 위 활동 | **미확인:** 토양성 생물을 수면성 포식자로 그리지 않음 |
- 토양 톡토기 파트에는 적합하나, 현행 `toktogi` 객체의 **수면 주위험 천적으로 우선 배치하지 않음**.

## 8. 검증 과제
- 토양 채집 표본에서 강모·협각·생식부와 제2다리를 확인해 종 동정.
- 먹이를 동정하고 '먹이로 제시'와 '포획·섭식 관찰'을 분리하여 실험을 기록.
- 물가 흙과 부유잎의 **실제 연결 여부**를 먼저 확인한 후 먹이망으로 연결.
