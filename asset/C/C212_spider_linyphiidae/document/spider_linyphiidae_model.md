# 접시거미과 (Linyphiidae) — 3D 외형 모델 명세서

> **기준:** `toktogi_model.md`의 외형 명세 범위(실루엣·크기·외부 기관·색채·표면·미정 수치). **대상 분류:** 과.
> **범위 주의:** 접시거미과는 다양한 종의 집합이다. 그물·몸통·눈·크기를 하나의 “표준 종”처럼 그리지 않고 시트형과 지표형 변형을 따로 만든다.
> **톡토기 관계:** 다른 톡토기류 DNA 검출과의 연결은 존재하지만 *S. aquaticus* 직접 포식은 미확인.

## 1. 전체 형태

| 항목 | 3D 실루엣·구성 |
|---|---|
| 기본 체형 | 머리가슴과 배가 좁은 허리로 연결; 작은 성체 거미에 다리 4쌍과 촉지 1쌍. |
| 기본 실루엣 | 머리가슴은 작고 배는 타원~둥근 형태가 흔함; 정확한 높이/폭은 선택 종마다 다름. |
| 기능형 A | *Erigone* 계열의 작은 지표형: 낮은 그물 또는 짧은 배회에 맞는 작은 몸. |
| 기능형 B | *Linyphia* 등 그물형: 긴 다리, 아래쪽으로 매달리는 자세, 비교적 큰 시트/돔그물. |
| 날개·더듬이 | 없음. 눈 앞의 촉지를 곤충형 더듬이로 잘못 만들지 않음. |
| 환경 부속물 | 거미줄은 생체 해부학의 일부가 아닌 별도의 환경 메시/곡선 객체. |

## 2. 크기·성차·성장 단계

| 구분 | 값과 적용 범위 |
|---|---|
| 과 참고 범위 | 교육자료 기준 대략 1.5–8mm. 모든 종의 극값·평균이 아님. |
| *Erigone atra* | 수컷 1.9–2.5mm / 암컷 1.8–2.8mm, 종별 예시. [L1] |
| *Bathyphantes gracilis* | 수컷 1.5–2.0mm / 암컷 1.9–2.5mm, 종별 예시. [L2] |
| *Linyphia triangularis* | 수컷 4.6–7.0mm / 암컷 5.0–8.0mm; 큰 그물형 예시. [L3] |

> **치수 해석:** 위 mm/cm는 자료의 **몸길이**이며, 부속지까지 포함한 전체 외접 크기와 다릅니다. 표본·단계·측정법을 보존합니다.

## 3. 부위별 외형

| 부위 | 모델링 요구 및 근거 범위 |
|---|---|
| 머리가슴 | 위에서 둥근~달걀형, 앞쪽 좁아지는 경우가 있으나 속별 변형이 큼. |
| 눈 | 보통 8안이 2열로 배열되지만 예외 가능. 선택 종 도판 없는 8안 위치 고정 금지. |
| 협각 | 작은 한 쌍의 아래로 향한 독니를 포함; 극도로 비대한 턱으로 그리지 않음. |
| 촉지 | 성숙 수컷은 복잡한 팽대형 교미촉지, 암컷은 상대적으로 단순. |
| 다리 | 4쌍, 길고 가는 마디형; 일부 수컷은 다리/머리가슴 형태가 특수함. |
| 배 | 타원형·아랫방향 매달림; 무늬·크기·체모는 종별로 달라짐. |
| 실젖 | 복부 후단의 작은 실 방출기관; 실 지지점을 어깨나 다리로 오설정 금지. |
| 그물 시트 | 대표 그물형은 수평에 가까운 연속 시트, 위/아래에 얽힌 장애실을 가질 수 있음. [L4] |
| 그물 변형 | 평판/돔/그릇형과 작고 낮은 지표형을 별도 프리셋으로. |
| 난낭 | 실로 포장한 알 덩어리는 종·부착기질마다 형태가 달라 기본 형상 미정. |

## 4. 색채·표면·재질

| 항목 | 재질·무늬 명세 |
|---|---|
| 바탕색 | 갈색·회갈색·흑갈색 등, 일부 등판은 밝고 배에 대비 무늬가 있음. |
| 배 무늬 | *Linyphia*와 *Erigone*의 무늬를 혼합하지 않으며 정확한 패턴은 종 선택 후 제작. |
| 광택 | 머리가슴은 얕은 각질 광택, 배는 경우에 따라 무광/실크색; 수치 재질은 미정. |
| 체모 | 정밀 모델에서 가는 다리 털과 배의 미세 털을 강조하되 길이를 임의 통일하지 않음. |
| 그물 재질 | 반투명 미세 곡선; 모든 실을 끈적한 접착 코팅처럼 묘사하지 않음. |

**재질 수치:** RGB/HEX, IOR, 금속성·거칠기·투명도, 강모 밀도는 명시된 출처에 없으면 **미정**이며 미술적 기본값을 생물 실측값으로 취급하지 않습니다.

## 5. 현미경·동정용 세부 형질

| 세부 | 구현 조건·주의 |
|---|---|
| 전열·후열 안구 | 보편 8안이 흔하더라도 무안·감소안 예외 가능; 3D 종 동정에는 사진 필요. |
| 수컷 두흉부 | Erigoninae 일부 수컷의 머리 돌기/융기를 과 전체 성체에 복사하지 않음. |
| 발톱·다리 가시 | 경절 가시식·발톱은 동정에 쓰이나 과 전체 공통 표준배치 없음. [L5] |
| 생식기 | 수컷 촉지와 암컷 epigyne/scapus는 종별로 매우 다름. |
| 그물 서식층 | 지면 0cm에 가까운 그물과 식생 위 높이 놓인 그물은 별도 배치 값 필요. |

## 7. 메시·리깅/LOD 제안 (제작 규칙; 생물 실험값 아님)

| 하위 구성 | 권장 메시·본·상태 |
|---|---|
| body | prosoma와 abdomen을 분리하고 회전 허리로 연결. |
| 8 legs | 보행·거미줄 진동 반응용 개별 관절 본. |
| pedipalps | 성숙 수컷/암컷 교체 메쉬. |
| web | 별도 커브 그래프; `sheet_flat`, `sheet_dome`, `ground_low` 프리셋. |
| silk_anchor | 실젖 뒤쪽에서 그물에 연결되는 본/포인트. |
| LOD | L0 그물의 시트 윤곽 유지; L1 얇은 실을 단순화; L2 그물 표시 선택적. |
| animation | build_web / hang_below / rush / wrap / repair 등은 기능형별 사용. |

## 8. 원 자료만으로 확정할 수 없는 값

- **미정:** 선택 종이 없을 때 대표 몸길이/배 모양/무늬.
- **미정:** 종별 눈 배열·경절 가시식·발톱의 세부.
- **미정:** 시트그물 면적·높이·실 굵기·실 간격의 공통값.
- **미정:** 수컷 촉지와 암컷 생식판의 정확한 3D 형상.
- **미정:** 물알둥근톡토기 포식이 확인된 접시거미 종.
