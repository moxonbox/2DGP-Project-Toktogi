# 물노린재 (Mesovelia vittigera) — 3D 외형 모델 명세서

> **기준:** `toktogi_model.md`의 외형 명세 범위(실루엣·크기·외부 기관·색채·표면·미정 수치). **대상 분류:** 종.
> **범위 주의:** 한국의 2024년 종 동정 검색표에서 **등면 녹색·암수 복부 말단**이 중요하다. 일부 근연종의 진한 줄무늬를 이 종에 섞지 않는다.
> **톡토기 관계:** 한국 기록종이지만 물알둥근톡토기 포식은 서식지 기반 가설에 그침.

## 1. 전체 형태

| 항목 | 3D 실루엣·구성 |
|---|---|
| 기본 실루엣 | 길쭉한 타원~거의 평행한 옆면, 가는 6개 다리와 한 쌍의 긴 더듬이. |
| 머리 | 너비와 길이가 비슷한 작은 머리, 양측 큰 겹눈. |
| 몸 | 짧은 앞가슴과 길어지는 가슴·배의 차이가 등면에서 보임. |
| 날개형 | 날개 없는 성충(apterous)과 길게 발달한 날개형(macropterous) 모두 보고됨. |
| 주둥이 | 머리 아래로 접힌 가늘고 짧은 흡즙형 입. |
| 서식 포즈 | 부유식물 잎 위 걷기와 수면 가까운 다리 접촉 자세. |

## 2. 크기·성차·성장 단계

| 구분 | 값과 적용 범위 |
|---|---|
| 성체 문헌 범위 | **2.0–3.5mm**: 태국 지역 종 연구. 한국 전체 개체군의 평균이 아님. [M2] |
| 암수 | 성별별 체장 범위 이번 자료에 없음. 수컷·암컷 복부 끝 생식형태는 다름. |
| 날개형 | 몸길이·가슴등판 실루엣에 차이 가능; 변형별 실측 미정. |
| 약충 | 불완전변태의 약충으로 날개형 성충과 형태를 혼동하지 않음. |

> **치수 해석:** 위 mm/cm는 자료의 **몸길이**이며, 부속지까지 포함한 전체 외접 크기와 다릅니다. 표본·단계·측정법을 보존합니다.

## 3. 부위별 외형

| 부위 | 모델링 요구 및 근거 범위 |
|---|---|
| 겹눈 | 머리 양측에 비교적 큰 둥근 겹눈, 머리 중심 앞끝과는 분리. |
| 더듬이 | 전체 길이의 약 0.6–1.0배라는 속 범위 소개; 4마디(과 일반). [M3] |
| 머리 감각털 | 머리 위 감각털(trichobothria) 배열은 정밀 모델에서 전문 검색표 참조. |
| 주둥이 | 머리 아래 접힌 4마디 rostrum(과 일반); 섭식 때 아래·앞으로 조절. |
| 등판 | 무시형에서 매우 짧은 앞가슴등판, 뒤 가슴등판 노출. [M3] |
| 배 | 길쭉하고 등면이 녹색, 암컷 복부 끝에 후방 돌기 없음(2024 검색표). [M1] |
| 수컷 말단 | 제8복판 가운데 검은 작은 가시 1개가 한국 검색표의 구별점. [M1] |
| 다리 | 3쌍 6개, 다리 후방쌍 상대적으로 김; 강모가 작은 다리. |
| 날개 | 장시형은 막성 날개가 등쪽에 접힘, 무시형은 별도 가슴등판 구조. |
| 눈·단안 | 무시형에서는 단안이 없고 장시형에서는 나타나는 것이 속·과 동정 특징. [M3] |

## 4. 색채·표면·재질

| 항목 | 재질·무늬 명세 |
|---|---|
| 종 색상 | 산 개체 등면은 **초록색**으로 기재(한국 2024 검색표). [M1] |
| 근연종 대비 | *M. thermalis*의 진한 측면 줄무늬와 *M. egorovi*의 갈색 몸을 기본형에 복제하지 않음. |
| 부속지 | 연황~황록색에 일부 갈색 미세 강모; 정확한 대비와 분포 미정. |
| 광택 | 배 표면은 비교적 매끈하고 부분광택; 수치형 메탈릭은 사용하지 않는 방향. |
| 날개형 | 막날개의 투명도와 녹색 배 노출은 날개형별 분리. |

**재질 수치:** RGB/HEX, IOR, 금속성·거칠기·투명도, 강모 밀도는 명시된 출처에 없으면 **미정**이며 미술적 기본값을 생물 실측값으로 취급하지 않습니다.

## 5. 현미경·동정용 세부 형질

| 세부 | 구현 조건·주의 |
|---|---|
| 복판 가시 | 수컷 제8복판 중간 작은 검은 가시 1개 vs *M. thermalis* 2개: 동정형. [M1] |
| 암컷 말단 | 복부 제8복판에 후방 돌기 없음; *M. egorovi*의 돌기형과 혼동 금지. |
| 무시형 검색표 | 이 단서는 **무시형에 적용되는 검색표**임을 표시. |
| 단안 | 없음/있음은 날개형과 연동할 것. |
| 비율 | 더듬이·뒷다리의 속 수준 범위를 종의 고정 치수로 바꾸지 않음. |

## 6. 필수 참조 시점·모델 변형

- [ ] 등면: 녹색 배·짧은 앞가슴등판
- [ ] 무시형 측면: 긴 더듬이와 뒷다리
- [ ] 장시형 등면: 날개 윤곽
- [ ] 정면: 겹눈·4마디 더듬이
- [ ] 복면: 암수 제8복판(정밀형)

> 표본 사진·논문 도판은 **형태 검증용 링크**로 사용하고, 재배포 권리는 별도 확인합니다.

## 7. 메시·리깅/LOD 제안 (제작 규칙; 생물 실험값 아님)

| 하위 구성 | 권장 메시·본·상태 |
|---|---|
| body | 머리/흉부/배 세 구역으로 분리. |
| legs | 6 다리의 가는 관절; 뒷다리 길이 차이. |
| antennae | 4마디 중심 분리. |
| rostrum | 흡즙 접촉용 작은 회전 본. |
| wing_variant | apterous/macropterous에 따른 등판·단안·날개 동시 교체. |
| sex_variant | 암수 복부 말단의 종별 형태 교체. |
| LOD | 미세 감각털은 근접 LOD, 초록 몸과 무시형 윤곽은 원경 유지. |

## 8. 원 자료만으로 확정할 수 없는 값

- **미정:** 성별·날개형에 따른 실측 체장과 배 비율.
- **미정:** 단안·겹눈 크기/위치와 감각털 배열.
- **미정:** 각 다리 마디와 발톱 수치.
- **미정:** 암컷 산란관 형태의 정밀 도판.
- **미정:** *S. aquaticus* 직접 흡즙 사례.
