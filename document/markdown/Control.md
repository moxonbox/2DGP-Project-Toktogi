# Toktogi 조작·입력 명세

2026-11-18 · v1.4 · Pico2D 후보: WASD 직접 회전·상황별 E·Ctrl 제동·Shift 달리기·F 공격. 원본 prototype의 이전 키는 비교용으로 보존한다. 실기 미검증.
키·장면별 소비·포커스는 이 문서, 행동 적격성·수치는 [시스템](game-design/011_toktogi_system_design_spec.md), 상태 전이는 [상태 머신](game-design/toktogi_state_machine.md#atlas-states), 이식 순서는 [Rebuild](Rebuild.md)를 따른다.

## 1. 플레이·F2 조작표

구조도는 이 절의 아래 두 표를 순서대로 읽는다. `[키]` 표기를 유지하며 새 입력도 대응 표에 반영한다.

### 플레이

| 입력 | 동작과 조건 |
| --- | --- |
| [A] / [D] | 접지 보행·연속 회전. 시작 자세에서 A는 화면 반대쪽, D는 화면 쪽으로 돌기 시작한다. 유지하면 180°·360°를 지나 같은 방향으로 계속 돌며 해제하면 현재 각도를 유지한다. 양쪽 유지 시 이동·회전 의도 0. 발 지지 검사를 거치며 공중 가로 속도를 직접 바꾸지 않는다. |
| [W] / [S] | A/D 입력 중에는 위 조준 / 아래 조준만 적용하며 A/D 회전 방향·속도는 바꾸지 않는다. 조준 자세를 표시하고 도약 승인 때 조준 값을 사용한다. W+S는 중립. A/D가 없을 때 단독 W=90°·S=270° 목표 회전은 유지한다. |
| [Ctrl] | 접지 제동·직접 회전 정지. 좌우 Ctrl을 각각 추적하고 둘 다 해제해야 논리 제동을 해제한다. 달리기보다 우선한다. |
| [Shift] | 유지 시 접지 달리기. 보행 목표 속도의 2배(habitat 72→144px/s), 회복 계수 .55 유지. 좌우 Shift를 각각 추적한다. |
| [Space] 누름 | Idle 선택, 작업·공격의 미실행 효과와 이전 미발사 요청 취소. 물리 속도·중력 유지. 누름 자체는 보행 제동이 아니다. |
| [Space] 뗌 | 현재 누름과 짝인 해제만 도약 요청. 유효 지지와 준비를 확인한다. 탄성 선행/후행 창은 착지 전 100ms/후 165ms다. |
| [E] | 가까운 적 공격 우선, 등불·씨앗 활성/수집, 먹이 앞 유지 섭식, 대상 없으면 손질. DOWN에 선택한 명령을 UP까지 유지한다. |
| [F] / [X] | 적격 접지의 단발 공격(F 기본·X 호환). 키 해제로 끊지 않으며 활성 `[78,162)ms`는 공격 본편 시작 기준이다. |
| [Q] | 접지에서 반대 방향으로 회전. 지지 부족이면 거절한다. |
| [Z] | 안정된 접지 대기·보행에서 360° 회전 후 시작 방향 복귀. 보행 시 위상별 제동을 연결한다. |
| [P] / [Esc] | Playing에서 일시정지, Paused에서 재개. 효과·예약을 정리하며 정지 중 표시 셀을 보존한다. |
| [R] | 활성 체크포인트 또는 시작점에서 새 도전. 먹이·씨앗·위험·타이머·예약을 초기화한다. |
| [F1] / [F2] / [Tab] | 플레이 / 모션·재질 검수 / 두 장면 전환. F2에서는 코스 시간이 멈춘다. |
| [C] / [V] | 플레이 미할당. 원안의 관계·공중 선회 입력을 복원하지 않는다. |

### F2 검수

| 입력 | 동작 |
| --- | --- |
| [↑] / [↓], 마우스 휠 | 검색 결과 안에서 모션 선택. 선택 시 시간·방향을 처음으로 돌리고 재생한다. |
| [←] / [→] | 이전·다음 셀로 이동 후 정지. 범위를 넘으면 첫/끝 셀에 머문다. |
| [Space] | 재생·정지. 비루프 종료 후 재생은 처음부터 시작한다. |
| [V] | 해당 클립이 지원하는 방향만 순환. 시퀀스·게임 시간표는 지정된 방향을 사용한다. |
| [M] | 실시간 조명 / Sprite / Base·Alpha / Normal / RM / Emissive / 윤곽선의 7개 보기 순환. |
| [L] / [F3] | 고정·마우스·이동 광원 / 발·작업 마커 표시 전환. 마우스가 프리뷰 밖이면 기준 광원을 쓴다. |
| [Ctrl]+[F], 검색칸 클릭 | 검색 시작. 이름·설명·한글 별칭을 공백 단어별로 대소문자 구분 없이 검색한다. |
| [Backspace] / [Enter] / [Esc] | 검색 중 문자 삭제 / 입력 종료 / 입력 종료. 검색 중 Esc는 플레이로 복귀하지 않는다. |
| 목록·재생·이전·다음·방향 버튼 | 대응 키와 같은 동작. 타임바는 표본 인덱스 비율로 셀을 선택하고 그 셀 시작 시각에서 정지한다. 셀 시간 길이가 같다고 가정하지 않는다. |
| 배경·배율 버튼 | 검수 배경 3종, Nearest 1×/2×/3× 순환. 플레이 화면 설정은 바꾸지 않는다. |
| 재질·광원 버튼 | 거칠기 원본/.22/.52/.85, 금속성 원본/0/.5/1, 발광 토글, 강도 1/.4/1.65를 검수에만 적용한다. |
| Normal 비교·Bloom 버튼 | 구현: 원본/평탄 Normal, Bloom 켜짐/꺼짐. 초깃값은 원본·발광 켜짐·Bloom 꺼짐. [재질 계약](2Dshader.md)을 따른다. |
| [F1] / [Tab] / [Esc] | 플레이 복귀. F1/Tab은 검색 중에도 장면을 바꾸며 검색·유지 입력을 정리한다. |

- 직접 회전은 Z의 62셀을 재사용한다. A/D는 360°/1.55초로 연속 회전하며 180°·360° 경계에서 보행이나 별도 회전 모션으로 교체하지 않는다. 중간 각도는 에셋 셀 단위로 표시한다.
- A/D 입력 방향을 바꾸면 현재 각도부터 반대로 회전한다. A/D+W/S에서는 원본 좌우 위/아래 조준 자세가 우선하며, 조준 해제 시 계속 진행 중인 회전 각도로 복귀한다. Ctrl은 회전을 멈춘다.
- 공중·작업·피격·착지·Q/Z 중에는 해당 모션이 우선한다. 행동은 기존 좌우 판정을 사용하며 회전은 안정된 접지에서 재개한다.

## 2. 이벤트 표현과 소비 순서

- [App](../../toktogi/prototype/app.py)의 GAME_KEYS·route_event·장면 분기를 이식 근거로 삼는다. 물리 키(scancode), 논리 키(keysym/게임 명령), DOWN/UP, repeat·modifier, SDL timestamp, 입력 순번·장면 세대를 보존한다.
- 이벤트는 [백엔드](Pico2DBackend.md)가 한 SDL 큐에서 한 번만 읽는다. Pico2D 1.5.1 get_events는 timestamp·modifier·포커스·TEXTINPUT/TEXTEDITING을 전달하지 않으므로 PySDL2 원시 이벤트를 변환한다. 입력 수집·창 처리는 같은 주 스레드에서 수행하며 큐를 중복 소비하지 않는다.
- 정렬 키는 정규화 시각과 수집 순번이다. 밀리초를 초로 변환하고 32비트 순환을 보정한다. 지연 이벤트는 현재 처리 틱보다 과거로 되돌리지 않되 원래 시각도 로그에 남긴다.
- 현행 route는 게임 키·포커스 획득=tick, 종료·포커스 상실·P/Esc/R/F2/Tab DOWN=close, F1 등=after다. close 뒤 같은 틱의 나머지 입력은 틱 뒤로 넘기는 순서를 보존한다.
- 활성 틱은 전환·물리·위험 접촉 후 tick 입력, 이어 발사·작업·타격을 처리한다. Space DOWN의 미실행 효과 취소와 틱 뒤 P/F2 전환을 같은 순서로 뭉뚱그리지 않는다.
- 전역 장면 전환, 검색 입력, 장면별 단축키 순으로 소비한다. 하나의 이벤트가 검색 문자와 게임 동작 또는 두 버튼을 동시에 실행하지 않게 한다.
- 게임·전역 단발키의 자동 반복/중복 DOWN과 짝 없는 UP은 무효다. F2 보완 정책은 목록·프레임·Backspace의 반복만 허용하고 M/L/V/F3·재생 토글은 누름당 한 번으로 한다.
- 동일 논리 키의 물리 키 집합을 추적한다. 포커스·일시정지·재시작·장면 전환 뒤에는 새 DOWN부터 수락한다. 차기 어댑터는 이미 큐에 들어간 이전 문맥의 게임 입력도 세대로 거절하되 종료/포커스 등 창 이벤트는 처리한다. 합성 Space UP으로 도약시키지 않는다.
- 현행 Timeline의 120Hz·max_ticks=240과 잔여 accumulator를 보존한다. 3초 지연 시 2초 처리 뒤 남은 1초를 다음 갱신에서 회수하며, 과거 이벤트를 소급 적용하거나 표시율에 맞춰 게임 시간을 잘라내지 않는다.

## 3. 장면·진행·작업의 수명

- Playing에서만 새 게임 행동을 수락한다. Paused는 물리·효과·표시 셀을 고정한다. Failed/Cleared는 새 행동·효과를 차단하되 종료 자세와 R·장면 조작은 제공한다.
- F2 진입은 코스와 작업 효과를 멈추고 섭식의 현재 복귀 자세 등 기존 표시 연결을 보존한다. F2의 원본 클립 seek나 재생이 Game 효과를 실행하지 않는다.
- 포커스 상실은 활성 플레이를 일시정지하고 유지키·예약·검색 조합 입력을 정리한다. 포커스 획득만으로 재개·작업·도약을 실행하지 않는다.
- 이미 확정한 등불·씨앗·먹이 소비·타격은 취소로 되돌리지 않는다. 아직 실행하지 않은 효과와 준비/탄성/회전 예약만 해당 수명에 맞게 닫는다.
- 아래 F/G 유지 표기는 비교용 원본의 내부 섭식/손질 명령이다. 후보의 물리 F는 공격이며 유지 섭식/손질은 E가 선택한 명령으로 처리한다.
- Q/Z 중 마지막 수락 작업·도약을 종료 경계에서 재검사한다. F/G 예약은 계속 유지 중이어야 한다. 새 Space DOWN·피격·지지 상실·장면 전환은 예약을 정리한다.
- F/G UP은 자신이 시작한 작업만 종료한다. F 복귀 중 E/F/G/X와 이동, F에서 공격 진입, 착지 셀별 재도약은 [시스템](game-design/011_toktogi_system_design_spec.md)·[전투](game-design/013_toktogi_combat_design_spec.md)의 경계를 보존한다.

## 4. 검색·마우스·표시 좌표

- 검색 문자열은 최대 100자, 확정된 Unicode TEXTINPUT으로 갱신한다. KEYDOWN 문자 변환으로 한글/IME 결과를 추정하지 않는다. 조합 중 TEXTEDITING은 확정 문자열과 구분한다.
- [SDL 텍스트 입력](https://wiki.libsdl.org/SDL2/SDL_StartTextInput)을 검색 시작/종료·장면 전환과 짝지어 켜고 끈다. 조합 중 Esc/Enter는 IME 소비 여부를 확인해 이중 종료·중복 확정을 방지한다.
- 검색 결과 0개는 빈 목록으로 표시하며 재생·방향·프레임 조작을 안전하게 무효화한다. 빈 결과가 기존 모션을 계속 조작하지 않게 한다.
- 한 번의 좌클릭은 최상위 적격 버튼 하나만 실행한다. 타임바·휠·광원 포인터는 창 좌표를 [백엔드 좌표 계약](Pico2DBackend.md#backend-coordinates)으로 변환한 뒤 처리한다.
- 마우스 광원은 마지막 유효 위치를 사용하고 프리뷰 밖에서는 기준 위치로 돌아간다. DPI 보정과 Pico2D y축 변환을 이중 적용하지 않는다.
- 키 도움말·F2 버튼·HTML의 게임 시간표와 구조도는 이 문서·MotionSet을 참조한다. 새 Normal/Bloom 버튼에 미정 단축키를 임의 배정하지 않는다.

## 5. 입력 인수 검사

- C-01: 10/15/20/30/60fps와 한 프레임 안의 DOWN/UP에서 발사·작업·타격 횟수, 시각, 종료 상태가 기준과 같다.
- C-02: 좌우 Ctrl·Shift 동시 누름/한쪽 해제, 달리기와 제동 우선순위, 중복 DOWN·repeat·고립 UP, 동시 방향·조준, 시각 동률의 입력 순서를 검사한다.
- C-03: Space 취소/해제와 탄성 창의 직전·경계·직후, Q/Z 예약과 F/G 조기 해제, 공격 활성 끝 `[162ms]`의 무타격을 확인한다.
- C-04: 효과 직전/직후 Pause·F2·포커스 상실·R을 실행한다. 복귀 후 유령 키·중복 효과·이전 세대 예약/대기 입력이 없어야 한다.
- C-05: F2 전 키·버튼, 0개 검색·한글/영문·IME·100자 제한·Backspace·Enter/Esc·장면 전환을 확인한다. 버튼과 키 결과는 같아야 한다.
- C-06: SDL timestamp 순환, 지연 큐·큰 dt·처리 한도, 100%/150% DPI의 클릭·휠·광원·타임바 위치를 검사한다.
- C-09: A/D 장시간 유지의 180°·360° 무중단 통과, 화면 안/밖 초기 방향, 임의 각도 정지·반대 키 중립, A/D+W/S의 조준과 회전 분리, Q/Z·점프·공격 우선, 회전 자세의 발 지지를 확인한다.
- C-07: 상태 머신의 키·조건, 구조도의 두 입력표, 실행 도움말을 대조한다. 게임 미할당 C/V와 F2의 V를 혼동하지 않는다.
- C-08: Level 경계에서 유지키·Space 짝·회전 예약·작업 효과가 보존되고, 실제 Pause/F2/R에서는 해당 정리 규칙이 적용되는지 [StageLevel](StageLevel.md)과 대조한다.
- 증거에는 원시/정규화 시각·순번·장면/진행·논리 키·기대/실제·효과 횟수·재현 로그를 기록한다. 이 문서 작성은 해당 검사 통과를 뜻하지 않는다.

## 6. seamless 구간의 입력

- [StageLevel](StageLevel.md)의 Level/stage 문맥 변경은 App 장면 전환이 아니다. 이동·조준·Space의 DOWN/UP·F/G 유지와 입력 세대를 그대로 보존한다.
- 경계에서 Q/Z·공중제비·공격·손질을 다시 시작하지 않는다. 실제 접촉/지지 상실·피격 등 기존 취소 조건을 판정하며 출입 이벤트가 효과를 발생시키지 않는다.
- Pause/F2에서는 월드 전환도 멈춘다. R만 새 도전 세대를 시작하며 목적 체크포인트의 Level/지지 준비 뒤 입력을 받는다. 로딩 지연을 합성 키 해제로 처리하지 않는다.

## 7. 문서 연결

- [Rebuild](Rebuild.md)는 구현 순서·완료 관문, [Pico2DBackend](Pico2DBackend.md)는 이벤트 수집·좌표·출력을 소유한다. 키 배치와 입력 수명은 여기서만 변경한다.
- [통합 기획](game-design/001_toktogi_game_design_spec.md#atlas-sources)의 controls 원본은 `Control.md#atlas-controls`다. 상태 머신의 기존 `atlas-controls` 앵커는 호환 링크로 유지한다.
- 현행 코드와의 차이는 F2 토글 반복 방지·IME 조합/포커스 정리·대기 입력의 세대 판정 등 보완 요구로 기록한다. 신규 키맵 편집기·게임패드·터치 입력은 이번 범위에 추가하지 않는다.
