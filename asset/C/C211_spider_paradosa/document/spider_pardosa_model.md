# 긴마디늑대거미속 (Pardosa spp.) — 3D 외형 모델 명세서

> **기준:** `toktogi_model.md`의 외형 명세 범위(실루엣·크기·외부 기관·색채·표면·미정 수치). **대상 분류:** 속.
> **범위 주의:** 속 전체에 단일 대표 실루엣·체장을 고정하지 않는다. 실제 종 선택 전에는 속 수준 형태 가이드로만 사용한다.
> **톡토기 관계:** 다른 톡토기류의 섭식 근거는 있으나 *S. aquaticus*의 직접 포식 미확인.

## 1. 전체 형태

| 항목 | 3D 실루엣·구성 |
|---|---|
| 기본 체형 | 머리가슴(prosoma)과 배(opisthosoma)가 좁은 허리마디(pedicel)로 연결된 두 덩이형 거미. |
| 몸 윤곽 | 머리가슴은 비교적 넓고 낮은 등판, 배는 뒤로 이어지는 타원형의 부드러운 덩이. |
| 자세 | 긴 보행다리 4쌍을 몸 양옆으로 펼치고 지면 가까이에서 탐색; 항상 정지한 X자 포즈로 고정하지 않음. |
| 주요 특징 | 이마 위 눈 3열(4·2·2)과 큰 뒤가운데눈(PME)·뒤가쪽눈(PLE)이 핵심. |
| 날개·더듬이 | 둘 다 없음. 앞쪽 짧은 다리처럼 보이는 한 쌍은 더듬이가 아니라 촉지(pedipalps). |
| 거미줄 | 복부 끝 실젖이 있지만 일반적으로 먹이 포획용 정착그물을 만들지 않음. |

## 2. 크기·성차·성장 단계

| 구분 | 값과 적용 범위 |
|---|---|
| 종 사례 A: P. amentata | 수컷 5.5–6.5mm / 암컷 6.0–8.0mm, **몸길이(다리 제외)**. [P1] |
| 종 사례 B: P. agrestis | 수컷 4.5–5.0mm / 암컷 약 5mm, **특정 종**의 자료. [P2] |
| 속 전체 | 단일 평균·최소·최대 길이 미정. 새끼·성체를 같은 비율로 단순 축소하지 않음. |
| 측정 기준 | 머리가슴 앞끝부터 배 뒤끝까지; 다리와 실은 외접 크기에서 별도 관리. |

> **치수 해석:** 위 mm/cm는 자료의 **몸길이**이며, 부속지까지 포함한 전체 외접 크기와 다릅니다. 표본·단계·측정법을 보존합니다.

## 3. 부위별 외형

| 부위 | 모델링 요구 및 근거 범위 |
|---|---|
| 머리가슴 | 갈색 외골격 등판; 머리와 가슴이 외관상 나뉘지 않는 일체형. |
| 눈 | 전열의 작은 4안, 그 뒤쪽에 큰 PME 2안, 더 뒤쪽·가쪽에 PLE 2안; 눈 높이·각도는 실사진 참고. [P3] |
| 위턱·독니 | 머리 앞아래에 좌우 한 쌍의 협각·독니. 굵은 앞부리로 과장하지 않음. |
| 촉지 | 입 양옆 1쌍, 다리보다 짧음; 성숙 수컷 촉지 끝은 둥글고 복잡한 교미기관. |
| 보행다리 | 4쌍·8개. 기절→전절→퇴절→무릎→경절→발허리→발마디의 관절성 마디. |
| 다리 말단 | 발톱과 털이 있으나 정확한 형상·발톱 수는 선택 종의 현미경 자료로 확정. |
| 배 | 둥근/계란형의 부드러운 체절 없는 외관; 숨구멍과 배쪽 생식구조는 정밀형에만. |
| 실젖 | 복부 아래·뒤쪽의 작고 짝지은 기관. 난낭 운반 애니메이션의 부착 기준. |
| 암컷 생식판 | 배 앞쪽 복면의 epigyne은 성체 암컷 종 동정용; 일반화된 장식문양 금지. |
| 강모 | 등판·배·다리의 미세 털과 감각 강모를 서로 다른 밀도로 표현. |
| 알주머니/새끼 | 선택적 부속 소품: 실젖에 붙인 둥근 난낭, 배 위에 올라탄 새끼. |

## 4. 색채·표면·재질

| 항목 | 재질·무늬 명세 |
|---|---|
| 바탕색 | 황갈색~회갈색/검갈색 계열. 색을 종 고정 RGB값으로 정의하지 않음. |
| 등판 무늬 | *P. amentata* 예시: 머리가슴 중앙의 밝은 세로띠, 양측의 변화하는 밝은 선. [P1] |
| 배 무늬 | 어두운 배에 심장무늬 또는 작은 담색 반점이 있을 수 있으며 종마다 다름. |
| 다리 | 황갈색 다리에 진한 고리무늬·점무늬가 생길 수 있음. |
| 표면 | 머리가슴에 약한 경질 광택, 배는 미세 강모로 무광에 가까운 질감; 정량 PBR 미정. |

**재질 수치:** RGB/HEX, IOR, 금속성·거칠기·투명도, 강모 밀도는 명시된 출처에 없으면 **미정**이며 미술적 기본값을 생물 실측값으로 취급하지 않습니다.

## 5. 현미경·동정용 세부 형질

| 세부 | 구현 조건·주의 |
|---|---|
| 큰 눈 분류 | 특히 큰 두 쌍은 **후중안(PME)**과 **후측안(PLE)**; 전중안(AME)으로 오기 금지. [P3] |
| 눈 반사 | 야간 광반사는 구조상 가능하지만 모든 눈을 발광재질로 만들지 않음. |
| 성별 동정 | 수컷 촉지·암컷 생식판, 종별 다리 털·무늬를 결합해 판단. |
| 종 미결정 | 속 대표모델은 *Pardosa sp.*로 표기, *P. amentata*의 무늬·크기를 한국종에 붙이지 않음. |
| 수면 접촉 | 일부 물가 종의 수면 접촉은 가능해도 속 전체의 수면 전용발·수영막 모델은 금지. |

## 6. 필수 참조 시점·모델 변형

- [ ] 등면: 중앙띠/눈 뒤쪽과 배 무늬
- [ ] 정면: 4·2·2 눈의 높이 차이
- [ ] 측면: 긴 다리와 낮은 지면 자세
- [ ] 복면: 실젖·성별 생식형태(정밀형)
- [ ] 암컷 난낭 운반 및 새끼 탑승(선택)

> 표본 사진·논문 도판은 **형태 검증용 링크**로 사용하고, 재배포 권리는 별도 확인합니다.

## 7. 메시·리깅/LOD 제안 (제작 규칙; 생물 실험값 아님)

| 하위 구성 | 권장 메시·본·상태 |
|---|---|
| root/prosoma | 머리가슴을 기준 좌표로 하고 abdomen을 좁은 허리 조인트로 연결. |
| legs_1..4_L/R | 관절마다 별도 본; 보행·돌진·회피를 위해 발끝 접지 가능. |
| palps_L/R | 수컷 성숙형의 촉지 끝은 성별 변형 가능한 교체 메쉬. |
| chelicerae_L/R | 먹이 접촉/물기 상태에서만 소폭 작동. |
| spinnerets+egg_sac | 난낭은 배 뒤쪽 부착 소품으로 분리, 배 위 새끼 역시 개별 소품. |
| LOD | L0 눈 배열/다리 관절/무늬 유지; L1 미세 털 노멀; L2 털 생략. |
| animation | walk, orient, lunge, bite, carry_egg_sac은 제안 동작명이며 속 공통 측정 속도는 아님. |

## 8. 원 자료만으로 확정할 수 없는 값

- **미정:** 선택된 실제 종의 다리 편길이·몸체 폭/높이·배 곡률.
- **미정:** 각 안구의 직경·눈 간격·촉지 세부.
- **미정:** 종별 강모 길이·밀도와 색무늬 경계.
- **미정:** 무게·점프/질주 속도·물표면 장력 접촉 조건.
- **미정:** 물알둥근톡토기 직접 포식 장면에 등장한 거미의 종.
