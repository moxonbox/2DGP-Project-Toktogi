# 유럽공통개구리(설명용) (Rana temporaria) — 3D 외형 모델 명세서

> **기준:** `toktogi_model.md`의 외형 명세 범위(실루엣·크기·외부 기관·색채·표면·미정 수치). **대상 분류:** 종.
> **범위 주의:** 이 종은 국내 자생종으로 취급하지 않는다. 성체 개구리와 꼬리가 있는 올챙이는 같은 모델의 단순 축소판이 아니다.
> **톡토기 관계:** 다른 톡토기 *Podura aquatica*의 먹이반응 실험에는 포함, *S. aquaticus* 섭식 미확인.

## 1. 전체 형태

| 항목 | 3D 실루엣·구성 |
|---|---|
| 체형 | 머리·몸통이 넓게 이어진 짧은 몸, 목이 잘 보이지 않는 무미양서류. |
| 머리 | 눈이 위쪽·양쪽에 돌출, 둥글고 높이가 있는 주둥이. |
| 앞다리 | 비교적 짧고 4개 손가락이 있는 앞다리 한 쌍. |
| 뒷다리 | 매우 길고 근육질의 대퇴·종아리, 물갈퀴 발가락. |
| 성체 꼬리 | 없음. 등쪽 세로 능선·피부 주름을 실제 뒷꼬리로 표현하지 않음. |
| 올챙이 | 큰 머리몸통·긴 납작한 꼬리·기본적으로 다리 없음에서 발달하는 별도 형태. |

## 2. 크기·성차·성장 단계

| 구분 | 값과 적용 범위 |
|---|---|
| 성체 크기 | 자연사 자료에서 흔히 **6–8cm**로 소개; 다른 자료는 최대 **11cm** 정도. [R1][R2] |
| 암수 | 암컷이 대체로 크며 몸통 깊이·번식기 팔 형태 차이 존재. |
| 성체 기준 | 보통 SVL(주둥이–항문길이) 성격의 몸길이로, 늘린 뒷다리까지 합치지 않음. |
| 올챙이 | 성체 크기와 변태 단계별 치수·꼬리비율 별도 확보 필요. |

> **치수 해석:** 위 mm/cm는 자료의 **몸길이**이며, 부속지까지 포함한 전체 외접 크기와 다릅니다. 표본·단계·측정법을 보존합니다.

## 3. 부위별 외형

| 부위 | 모델링 요구 및 근거 범위 |
|---|---|
| 눈 | 가로방향 타원 동공, 눈 위쪽 선명한 융기. |
| 고막 | 눈 뒤 원반형 tympanum; 눈 크기의 최대 약 3/4 사례. [R1] |
| 안면 띠 | 눈에서 고막을 지나 뒤쪽으로 이어지는 짙은 갈색 “마스크” 무늬. |
| 주둥이 | 둥글고 약간 높은 콧등, 좌우 코구멍 한 쌍. |
| 입 | 넓게 열리는 턱선; 먹이 포획용 혀는 입 안쪽 별도 메쉬. |
| 목·몸통 | 목을 굵은 관절로 분리하지 않으며, 배는 넓고 부드러움. |
| 등옆주름 | 등과 옆구리 경계에 길게 이어지는 **dorsolateral folds**. [R1] |
| 앞다리 | 양쪽 앞다리, 손가락 4개와 구분되는 손끝. |
| 뒷다리 | 긴 허벅지/종아리와 발, 긴 발가락 5개, 비교적 발달한 물갈퀴. |
| 발바닥 | 발가락 관절과 안쪽 발허리 혹(metatarsal tubercle)은 정밀형. |
| 올챙이 | 별도 larva 씬: 둥근 머리몸통·옆으로 납작한 꼬리와 꼬리지느러미. |

## 4. 색채·표면·재질

| 항목 | 재질·무늬 명세 |
|---|---|
| 등색 | 갈색·올리브·회색, 때로 붉거나 노란 변이; 하나의 색 고정 금지. |
| 마스크 | 눈 뒤의 어두운 영역을 기본 특징으로 표현. |
| 무늬 | 등의 불규칙한 어두운 점·어깨 사이 V자 무늬가 있을 수 있음. [R1] |
| 배 | 흰색~회색, 얼룩무늬가 관찰되기도 함. |
| 피부 | 매끄러운 편의 습윤 피부와 작은 돌기. 비늘·거북갑·점액이 떨어지는 과장은 금지. |

**재질 수치:** RGB/HEX, IOR, 금속성·거칠기·투명도, 강모 밀도는 명시된 출처에 없으면 **미정**이며 미술적 기본값을 생물 실측값으로 취급하지 않습니다.

## 5. 현미경·동정용 세부 형질

| 세부 | 구현 조건·주의 |
|---|---|
| 고막 | 외부 귓바퀴가 아닌 눈 뒤 평평한 원반형. |
| 등옆주름 | 양측 등에서 옆으로 이어지는 융기선; 체표 무늬가 아니라 형상 특징. |
| 동공 | 가로 타원 동공으로 설정; 초승달·원형 고정 금지. |
| 손/발 | 앞발 4손가락, 뒷발 5발가락; 물갈퀴는 주로 뒷발. |
| 올챙이 단계 | 꼬리·아가미/호흡기관·먹이는 생활사 단계별 다름. |

## 6. 필수 참조 시점·모델 변형

- [ ] 등면: 검은 마스크·등옆주름
- [ ] 측면: 눈·고막·주둥이
- [ ] 정면: 입/동공/코구멍
- [ ] 뒷다리 폄/접힘과 물갈퀴
- [ ] 올챙이–변태기–성체 별도 턴어라운드

> 표본 사진·논문 도판은 **형태 검증용 링크**로 사용하고, 재배포 권리는 별도 확인합니다.

## 7. 메시·리깅/LOD 제안 (제작 규칙; 생물 실험값 아님)

| 하위 구성 | 권장 메시·본·상태 |
|---|---|
| root/body | 몸통과 머리 표면을 연속적인 변형 메쉬로. |
| forelimbs | 앞다리 2개, 손가락 4개 관절. |
| hindlimbs | 긴 관절사슬 2개와 물갈퀴 발바닥. |
| jaw/tongue | 입 개폐와 짧은 먹이 포획 혀 포즈. |
| eyes | 가로 동공을 유지하며 눈꺼풀/눈 반사. |
| larval_variant | 올챙이는 꼬리·지느러미·성장단계가 다른 별도 리그. |
| animation | crouch, hop, swim, tongue_snap, amplexus는 생태 동작 제안. |

## 8. 원 자료만으로 확정할 수 없는 값

- **미정:** 성별·연령별 피부 무늬와 실제 신체 비율.
- **미정:** 자연 서식지에 따른 몸색의 상세 패턴.
- **미정:** 혀 길이·탄성, 도약 거리·관절 속도.
- **미정:** 변태 단계별 몸과 꼬리 길이·손발 발달 비율.
- **미정:** *S. aquaticus* 직접 포식 및 한국 자연 개체군.
