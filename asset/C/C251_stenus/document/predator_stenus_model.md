# 딱부리반날개속 (Stenus spp.) — 3D 외형 모델 명세서

> **기준:** `toktogi_model.md`의 외형 명세 범위(실루엣·크기·외부 기관·색채·표면·미정 수치). **대상 분류:** 속.
> **범위 주의:** 속 수준 모델; 입술 사출 장치가 외형·리깅의 핵심이다. 모든 Stenus 종의 색·크기·수면 스키밍을 하나로 고정하지 않는다.
> **톡토기 관계:** Stenus 속 여러 종에서 톡토기 포획 확인; *S. aquaticus* 직접 먹이 실험 미확인.

## 1. 전체 형태

| 항목 | 3D 실루엣·구성 |
|---|---|
| 실루엣 | 가늘고 길며 배가 완전히 덮이지 않는 반날개과 딱정벌레형. |
| 머리 | 몸에 비해 넓은 머리, 좌우에 매우 큰 돌출 겹눈. |
| 가슴 | 중앙의 앞가슴등판이 구별되고 짧은 딱지날개가 그 뒤를 덮음. |
| 배 | 딱지날개 밖으로 길게 노출되는 유연한 복부 마디가 이어짐. |
| 다리 | 세 쌍 6개, 길고 빠른 지표 보행에 적합한 윤곽. |
| 포식 장치 | 입에서 멀리 뻗는 아랫입술(labium)과 끝의 접착 패드가 가장 특징적임. |

## 2. 크기·성차·성장 단계

| 구분 | 값과 적용 범위 |
|---|---|
| 종 사례 | 한국산 *Stenus koreanus* **3.2–3.3mm**(2015 표본). [S1] |
| 속 공통 크기 | 종 다양성으로 고정 평균 미정. 예시를 모든 Stenus의 몸길이로 쓰지 않음. |
| 암수 | 성별 체장·배 끝 차이는 모델링 대상 종 선택 후 확정. |
| 유충 | 성충과 다른 형태(완전변태). 성충 축소판으로 생성 금지. |

> **치수 해석:** 위 mm/cm는 자료의 **몸길이**이며, 부속지까지 포함한 전체 외접 크기와 다릅니다. 표본·단계·측정법을 보존합니다.

## 3. 부위별 외형

| 부위 | 모델링 요구 및 근거 범위 |
|---|---|
| 겹눈 | 머리 양측에 매우 큰 둥근 돌출 겹눈; 시선 방향 가독성의 핵심. |
| 더듬이 | 한 쌍의 마디형 더듬이를 눈 사이 앞부분에 배치. |
| 위턱 | 아랫입술과 별도 한 쌍의 씹는 턱. 먹이 제압에도 쓰일 수 있음. |
| 아랫입술 | 머리 속 수납 상태와 길게 전개된 사출 상태를 독립 형태로. [S2] |
| 접착 패드 | 사출형 labium 끝에 두 개의 끈적한 패드(paraglossae); 미세형에서 재현. [S2] |
| 앞가슴등판 | 머리와 딱지날개 사이 중앙의 구획, 표면 점각은 종별. |
| 딱지날개 | 앞쪽 짧은 좌우 2장, 배 대부분을 덮지 않음. |
| 뒷날개 | 일부 비행형에서 딱지날개 아래 접힌 막날개; 종·개체별 날개상태 확인. |
| 배 | 여러 마디가 밖으로 드러나고 끝쪽은 비교적 유연; 방어샘은 외형에서 과장하지 않음. |
| 다리 | 6개의 길쭉한 마디 다리, 끝의 작은 발톱. |

## 4. 색채·표면·재질

| 항목 | 재질·무늬 명세 |
|---|---|
| 바탕 | 검갈색·짙은 회갈색 계열이 흔하지만 종류에 따라 변이. |
| 점각 | 머리·앞가슴·딱지날개에 미세한 홈/점각이 있을 수 있음. |
| 털 | 미세 강모와 복부 털을 근접 LOD에 제한. |
| 겹눈 | 검정/암갈색의 반사되는 겹눈. 무조건 하나의 투명 구슬로 과장하지 않음. |
| 접착 기관 | 아랫입술 끝의 작은 패드는 다른 턱과 색/재질을 구분할 수 있음. |

**재질 수치:** RGB/HEX, IOR, 금속성·거칠기·투명도, 강모 밀도는 명시된 출처에 없으면 **미정**이며 미술적 기본값을 생물 실측값으로 취급하지 않습니다.

## 5. 현미경·동정용 세부 형질

| 세부 | 구현 조건·주의 |
|---|---|
| 먹이사냥 장치 | labium은 상시 밖으로 나와 있는 더듬이가 아니라 짧게 수납되었다가 사출됨. |
| 날개 명칭 | 짧은 딱지날개(elytra)와 아래 막날개를 구별; 딱지날개 없음으로 표현하지 않음. |
| 종 사례 | 수면에 떠서 화학성 분비물로 이동하는 일부 종을 모든 종의 기본 운동으로 주지 않음. |
| 눈 형태 | 큰 눈은 속 특징이지만 안구 직경·간격은 종별 미정. |
| 동정 | 몸표면 점각·복부·수컷 교미기관은 해당 종 도판 필요. |

## 6. 필수 참조 시점·모델 변형

- [ ] 정면: 거대한 돌출 겹눈·협각 아닌 위턱
- [ ] 측면: 짧은 딱지날개·노출 복부
- [ ] 등면: 머리-앞가슴등판-딱지날개 경계
- [ ] 아랫입술 수납/전개 전후
- [ ] 수컷·암컷 복부 끝 비교(정밀형)

> 표본 사진·논문 도판은 **형태 검증용 링크**로 사용하고, 재배포 권리는 별도 확인합니다.

## 7. 메시·리깅/LOD 제안 (제작 규칙; 생물 실험값 아님)

| 하위 구성 | 권장 메시·본·상태 |
|---|---|
| head | 돌출 겹눈·더듬이·주둥이 등을 하위 메쉬로. |
| labium | telescoping/shape-key로 수납↔사출 구현; 패드 끝 제어. |
| mandibles | 좌우 가동 위턱 별도. |
| elytra | 짧은 2장, 뒤쪽 막날개와 분리. |
| abdomen | 노출 마디의 작고 유연한 굽힘 본. |
| legs | 6 다리 보행, 지면 및 일부 수면 상태 별도. |
| animation | survey, aim, labial_strike, mandible_bite 등 제안; 수치형 사출속도 미정. |

## 8. 원 자료만으로 확정할 수 없는 값

- **미정:** 속 전체의 성체 길이·무늬·배 비율.
- **미정:** 종별 주둥이 최대 사출길이와 패드 접착면적.
- **미정:** 다리/더듬이 마디별 각도·폭.
- **미정:** 복부 분비선 외형과 수면 이동 빈도.
- **미정:** 물알둥근톡토기 직접 공격·포식 확률.
