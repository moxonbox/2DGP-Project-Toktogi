# 접시거미과(Linyphiidae) — 2DGP 생물 명세서

> **범위:** 거미목의 **과(family)** 객체. 단일 크기·그물·식성을 가진 종이 아니라 다양한 속을 포함하는 기능군이다. `[과 일반]`·`[속 연구]`·`[종 사례]`·`[미확인]`을 구별한다.

## 1. 분류·대표형
- 분류: 동물계 → 절지동물문 → 거미강 → 거미목 → **접시거미과 Linyphiidae Blackwall, 1859**. [L01][L05]
- 영명: sheet-web weavers, money spiders. 대표 연구 속 *Erigone*, *Tenuiphantes*, *Bathyphantes*, *Microlinyphia*; 특정 속을 과 전체의 표준으로 삼지 않는다. [L02][L03]
- 기능형: **낮은 시트그물·지표 배회형**, **식생 위 비교적 높은 시트/돔그물형**, **그물이 감소한 형태**. [L01][L03]

## 2. 몸길이·외형·감각
| 요소 | 자료상 내용·제한 |
|---|---|
| 과 참고 크기 | **약 1.5–8 mm**, 교육용 범위이며 전 세계 절대 최소·최대/평균 아님. 측정은 다리 제외 몸길이. [L02] |
| *Erigone atra* | 수컷 **1.9–2.5 mm**, 암컷 **1.8–2.8 mm**; 한국 분포 기록. [L11] |
| *Bathyphantes gracilis* | 수컷 **1.5–2.0 mm**, 암컷 **1.9–2.5 mm**; 한국 분포 기록. [L12] |
| *Tenuiphantes tenuis* | 수컷 **2.0–3.2 mm**, 암컷 **2.0–4.3 mm**; 한국 분포 근거로 전용 금지. [L13] |
| *Linyphia triangularis* | 수컷 **4.6–7.0 mm**, 암컷 **5.0–8.0 mm**; 종별 큰 그물형 예시. [L14] |
| 외형 | 작은 머리가슴·타원형 배·8개 다리·실젖; 갈색~검정 또는 무늬. 종마다 체형/색상/수컷 머리 변형이 다름. [L01][L04] |
| 눈·생식기 | **8안이 흔하지만 예외 존재**; 성숙 수컷 촉지와 암컷 생식판이 종 동정에 중요. [L01][L09] |
- 촉각·실 진동·화학 단서로 먹이와 짝을 감지하지만 **공통 탐지거리·성별 크기 차이·독량·속도는 미확인**.

## 3. 거미줄·사냥 행동
- 전형적인 그물형은 식물 사이 **수평 시트(sheet)**와 위쪽의 방해실을 형성; 시트 아래에서 대기하다 먹이 접촉/진동에 반응해 접근·물기·섭식. [L02][L03]
- 일부는 **돔형**, 일부 *Erigone* 등은 **지면 가까운 작은 그물+배회**, 일부는 포획 그물 기능이 감소. **과 전체를 하나의 접시그물로 그리지 않는다.** [L01][L03]
- 행동 순서: `그물 위치 선정 → 실 건설 → 아래쪽 대기 → 진동 탐지 → 접근·제압 → 섭식 → 수리/이동` (**그물형 개념 모델**).
- 그물 크기·높이·실 가닥 수와 유지 주기는 종·환경마다 다름. 영국 보리밭 연구의 **그물 147개**에서는 높이와 면적의 상호작용이 식단과 관련됐다. [L03]
- 그물은 접착판처럼 항상 자동포획하지 않으며, 먹이 움직임·위치·거미 반응에 따라 결과가 달라진다.

## 4. 서식·활동·분산
- **서식:** 초지, 밭, 숲 낙엽층, 관목과 습지 가장자리 등 다양한 육상 공간. 그물 위치는 `litter_low / grass_low / vegetation_high / roaming` 등으로 분리. [L02][L03]
- **활동:** 기다림·짧은 돌진·그물 수리; 교란 시 실을 타고 떨어지거나 숨을 수 있음. 과 전체를 낮/밤 전용으로 지정하지 않는다. [L02]
- **공중분산(ballooning):** 작은 개체가 실을 뻗어 바람·상승기류로 이동. 프랑스 농경지 2000–2002년 지상 12m 채집 **10,879개체** 조사에서 접시거미과가 우세했다. [L06]
- 같은 연구에서 풍속 약 **4m/s 이상에서 감소, 5.5m/s 이상에서 거의 관찰되지 않음**은 **그 연구 환경의 관찰값**이며 세계 공통 비행 한계가 아니다. [L06]
- 수면 위 거미줄/개구리밥 위 착지 가능성만으로 `toktogi`와의 접촉 또는 직접 포식이 입증되지는 않는다.

## 5. 먹이·포식 근거
- 소형 곤충·진딧물·총채벌레·톡토기류 등 **종·그물 높이에 따라 달라지는 먹이**를 이용한다. [L03]
- 2018년 웨일스 경작지 채집·2022년 발표 DNA 연구: 거미 **5속 합계 300개체 처리, 244개체 분석 가능**, 먹이 분류단위 **89개**는 전체 합계. [L03]
- 그 연구에서 톡토기과 **Bourletiellidae** DNA가 주로 *Erigone*·*Tenuiphantes*에서 확인됐다. *S. aquaticus*의 과는 **Sminthurididae**로 서로 다르다. [L03][L10]
- 별도 습지 DNA 연구의 **54.9% 톡토기 양성**은 **Linyphiidae와 Hahniidae를 섞은 시트형 그물거미 표본**이므로 접시거미과 전체 검출률로 전용 금지. [L07]
- **DNA 검출 = 특정 먹이 섭취 증거**이지만 공격 횟수·일일 섭식량·포획 성공률은 아니다.

## 6. 생식·성장·천적
- 성숙 수컷은 촉지로 정자 전달, 암컷은 난낭에 알을 낳고 부화 유체는 여러 번 탈피한다. 난낭 형태·알 수·구애 동작은 종에 따라 차이. [L02][L04]
- ***Oedothorax retusus***는 수컷 두흉부 분비물이 관련된 **미각성 구애**의 종 사례가 있으나 과 전체 기본 행동은 아니다. [L15]
- 여러 종 유체는 실분산 가능. 수명은 교육자료에 대개 1년 이내로 추정되나 **과 전체 확정 평균값이 아니다**. [L02][L06]
- 다른 거미·개미·지네·딱정벌레·소형 척추동물의 포식 대상이 될 수 있으나, 주요 천적의 종별 순위·빈도는 미확인. [L02]

## 7. `toktogi` 관계
| 관계 | 판정 |
|---|---|
| 일부 접시거미속 ← 다른 톡토기류 | **먹이 DNA 기록 있음** [L03] |
| `toktogi`(*S. aquaticus*) → 미동정 거미 | **종 수준 사진 관찰 있음** [L10] |
| `toktogi` → 접시거미과 객체 | **미확인**: 사진의 거미는 과 동정되지 않음 |
| 한국 기록 종 → 대상 연못의 포식자 | **미확인**: 한국 분포 ≠ 같은 연못 동시출현 [L11][L12] |

## 9. 현장 검증·주의
- 그물의 `형태/높이/면적/수면과의 상대 위치`, 거미의 `종/성별/성숙도/몸길이`, 먹이의 종 동정 기록.
- `그물 접촉→포획 시도→물기→섭식/탈출`을 구분; 먹이의 DNA 과 수준 동정을 *S. aquaticus* 종 동정으로 바꾸지 않는다.
- 식물상·풍속·온습도·시각·계절 기록. **과 전체 평균 크기·그물면적·활동시간·수명·포식률을 임의로 채우지 않는다.**
