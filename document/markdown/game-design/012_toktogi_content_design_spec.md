# 톡토기 콘텐츠 기획 명세

기준은 2026-11-17 설치본 `framework-r4`와 플레이 명세 v2.1이다. 현행 콘텐츠는 1인 코스 한 개다. 조작·물리는 [시스템 기획](011_toktogi_system_design_spec.md), 가시 판정은 [전투 기획](013_toktogi_combat_design_spec.md)을 따른다.

차기 [Stage·Level 명세](../StageLevel.md)는 수면 위 개구리밥 발판과 연꽃잎 위 구간을 seamless하게 연결한다. 아래 한 코스의 배치·완주 수치는 현행 회귀 프로필이며 새 두 Level의 치수로 복제하지 않는다.
수면 식물은 발판 환경으로 포함하고 수영·부력·수면 행동·산란은 제외한다. 새 구간의 목표·대상·체크포인트는 Level 객체 키와 Stage 진행 규칙으로 관리한다.

## 1. 코스 목표와 구간별 역할

물알둥근톡토기를 조작해 중간 등불을 켠 뒤 정상 발판에 멈춘다. 코스는 **보행과 일반 도약 → 위치를 맞추는 작업 → 탄성 타이밍 → 가시 앞 제동·공격 → 안정 착지** 순으로 규칙을 한 가지씩 추가한다.

좌표는 화면 위쪽이 작은 y인 논리 px다. 발판 범위는 x 양끝을 포함한다. 높이 차는 직전 주 경로 발판 기준이다.

| 구간 | x 범위 | 상판 / 하단 y | 상승 | 콘텐츠와 요구 동작 |
| --- | --- | --- | --- | --- |
| 1층 시작 | 35–201 | 476 / 500 | — | 시작점 (120,476), 먹이 (130,476). 좌우 이동·제동·조준을 연습하고 일반 도약으로 2층에 오른다. |
| 2층 중간 등불 | 243–407 | 404 / 424 | 72px | 등불 (339,404). 접지 상태에서 접근과 방향을 맞춰 E로 켠다. 이 플래그는 체크포인트 활성과 클리어에 필요하다. |
| 3층 탄성 잎 | 398–603 | 331 / 350 | 73px | 체크포인트 (486,331), 씨앗 (545,331). 탄성 착지 창을 이용해 상층으로 재도약한다. 씨앗은 선택 콘텐츠다. |
| 4층 가시 | 607–858 | 209 / 228 | 122px | 가시 껍질 (723,209). 너무 가까이 닿기 전에 제동해서 X로 제거하거나, 접촉 조건을 피하는 경로를 사용한다. |
| 5층 목표 | 817–950 | 125 / 144 | 84px | 목표 발판에 접지하고 지정 구간에서 멈춘다. 높이만 넘거나 옆면을 스쳐도 클리어되지 않는다. |
| 하단 회수 | 354–606 | 515 / 532 | — | 아래로 떨어질 때 정상 착지 가능한 발판. 코스 이탈 경계를 넘기 전에는 도전을 계속할 수 있다. |

- **필수 조건.** 중간 등불 활성화와 목표 발판 정지다. 가시 제거·섭식·씨앗 수집·손질은 클리어 플래그에 포함하지 않는다.
- **대표 검증 경로.** x≈127에서 1층 일반 도약, x≈339에서 제동 후 E, 3층 착지 후 탄성 창에서 재도약, x≈690에서 X, x≈746에서 최종 도약, 목표 발판 Shift 정지. 기존 자동 입력의 위치이며 강제 웨이포인트가 아니다.
- **도달성 검사.** 선행 속도, 제동, 착지 회복, 조준, 탄성 성공 여부를 고정해 각 높이와 착지 폭을 검수한다. 기본 기록은 13.75초·도약 4회·탄성 1회 완주다.

## 2. 상호작용과 피드백

E·F는 접지, 대상 범위, 작업 트랙의 필수 지지발을 검사한다. 수락에는 현재 방향의 효과 표본(섭식 220ms, E 200ms)의 입/작업 마커를 피벗 기준으로 코스에 투영한다. 플레이어를 대상 앞에 자동 배치하지 않는다.

| 콘텐츠 | 조작·대상 접점 | 수락 및 효과 | 종료와 유지 |
| --- | --- | --- | --- |
| 중간 등불 | E DOWN, (339,411) | 방향별 작업 소켓에서 3.5px 이내. E 후보에서 씨앗보다 먼저 검사. 동작 시작 후 200ms에 접촉을 다시 확인해 활성화한다. | 켜진 등불에 같은 효과를 주지 않는다. E 해제로 수락된 단발 작업을 끊지 않으며 효과 시점에 닿지 않으면 해당 시도는 지급 없이 끝난다. |
| 씨앗 | E DOWN, (545,340) | 동일한 작업 거리와 200ms 재확인. 적격 씨앗을 수집하면 수집 플래그를 켜고 표시를 제거한다. | 한 도전에서 1회 수집. 목표 조건이나 전투 보상과 연결되지 않는다. |
| 먹이 | F DOWN/유지, (130,461) | 입 마커 3.5px 이내, 초기 4회분. 기본 준비 160ms 뒤 400ms 주기를 실행하며 220ms에서 주기당 1회분을 소비한다. | F 해제·접촉 상실·고갈 시 중단한다. 소비한 양은 유지하며 피해·HP 회복을 적용하지 않는다. |
| 자기 손질 | G DOWN/유지, 왼쪽을 향한 충분한 지지면 | 전체 3.96초. 준비 6발 → 더듬이 손질 LH·RF·RM·RH 지지 → LF·LM을 내리지 않는 연결 → 도약기관 손질 RF·RM·RH 지지. | 완료 뒤 G를 계속 눌러도 자동 재시작하지 않는다. G 해제·지지 부족은 현재 셀에서 복귀한다. 도약·치유 효과는 없다. |
| 탄성 잎 | 3층 착지 전후 Space UP | 탄성은 발판 종류와 착지 시각으로 판정한다. 잎에 접촉만 해서는 자동 발사되지 않는다. | 유효한 후행 재도약 창에서 잎 상단을 연두색으로 강조한다. |

- **작업 중단.** Space DOWN, 피격, 지지 상실, 장면 전환 등은 미실행 효과를 취소한다. 이미 켠 등불·소비한 먹이·수집한 씨앗에 영향을 소급하지 않는다.
- **포즈 연결.** F 해제는 현재 셀부터 복귀한다. 새 보행·재섭식·손질·공격으로 들어갈 때 직전 포즈를 연결한다. G의 두 손질은 중간 지지 전환으로 이어진다.
- **플레이 화면.** 별도의 HUD나 장식 배경 없이 발판·등불·씨앗·먹이·가시를 표시한다. E/F 적격 대상을 연두색으로 바꾸고 거절 시 캐릭터에 180ms 틴트를 적용한다.

## 3. 클리어·실패·재시작

| 사건 | 판정 및 상태 변화 |
| --- | --- |
| 체크포인트 활성 | 중간 등불이 켜진 상태로 3층 탄성 발판에 착지한다. 해당 발판의 실제 지지가 필요하다. 활성 뒤 깃발을 표시한다. |
| 목표 클리어 | 목표 발판 접지 + 중간 등불 켜짐 + `839 < x < 940` + `abs(vx)<1px/s`를 연속 200ms 유지한다. 조건을 벗어나면 누적 시간이 0이 된다. |
| 코스 실패 | `x < −68`, `x > 1028`, `y > 585` 중 하나를 충족한다. 낙하 중 회수 발판에 착지하면 실패를 피할 수 있다. |
| R (활성 체크포인트) | (486,331)에서 등불·체크포인트를 켠 상태로 시작한다. 오른쪽을 바라보고 속도 0, 등장 포즈를 표시한다. 배치 자체에 탄성 보너스를 주지 않는다. |
| R (체크포인트 미활성) | (120,476)에서 시작하며 등불은 꺼진 상태다. 양쪽 재시작 모두 먹이 4회분·가시·미수집 씨앗을 복구하고 타이머, 동작, 예약을 초기화한다. |

정확한 중간 저장 복원은 보류다. 체크포인트는 도전 재시작 위치와 등불 활성만 유지하며 먹이·전투·수집 시점의 상태를 되살리지 않는다.

## 4. 코스·대상 제작 계약

- **배치 데이터.** 발판마다 x 시작·끝, 상판·하단 y, 종류를 지정한다. 탄성은 지정된 `elastic` 표면에만 적용한다. 목표 발판은 한 개이며 그 범위 안에 목표 구간을 둔다.
- **배치 유효성.** 시작점·체크포인트가 지정 발판 위에 있고, 해당 방향의 대기 자세를 받쳐야 한다. Capsule이 다른 고체와 겹치는 좌표는 거절한다. 실패 경계는 시작점·체크포인트·목표 구간을 포함해야 한다.
- **변경 검수.** 발판 간격을 바꿀 때 도약 정점뿐 아니라 Capsule의 머리 공간과 실제 착지 폭을 대조한다. 작업 대상을 옮기면 양쪽 방향의 마커·도달 거리와 애니메이션 전체의 지지발을 다시 확인한다.
- **선택 콘텐츠.** 조사(`inspect`)나 방울 손질을 플레이에 추가할 경우 대상·발동 입력·가시 단서·종료 조건·보상을 같은 프로필로 정의한다. 관찰 클립만으로 성공이나 자원 효과를 정하지 않는다.

## 5. 에셋, 검수와 범위

- **캐릭터.** integrated-r5 리그를 기반으로 한 128px 픽셀 스프라이트. 둥근 몸·여섯 다리·더듬이·도약기관을 애니메이션에서 구별한다. 공중제비의 시간과 회전 수는 게임 연출이다.
- **재생 분류.** 원본 82클립·17전환, 런타임 보조 146프로필, 게임 시간표 12개, 입력 리플레이 4개. F2·[모션 HTML](../../../asset/C/C011_toktogi/ToktogiMotionPreview.html)에서 총 261항목을 확인한다. 원본 1,444셀과 보조 930셀은 각 5패스다.
- **플레이와 검수.** 손질 06–07은 G로 사용한다. 08 방울 손질 등 추가 관찰 변형과 개체 간 결속·운반 장면은 검수 자료다. 수영·부력·수면 행동·산란·구애·지속 관계·공동 도약은 플레이 범위에서 제외한다. 수면 식물 발판의 구간 연결은 차기 Stage·Level 범위다.
- **검수 조작.** F2에서 클립·프레임을 선택한다. M은 재질 보기, L은 광원, F3은 접지 마커, V는 지원 방향, Ctrl+F는 검색이다. Nearest 1×/2×/3×로 자세와 접촉을 확인한다.
- **인수 확인.** 미승인 E/F/G 무효과, 적격 대상 표시와 판정 일치, E 단발과 F 주기 소비, 06–07 지지 전환, 탄성 잎에서 고도 도달, 체크포인트 전후 R, 목표 스침·정지 비교를 검수한다.
