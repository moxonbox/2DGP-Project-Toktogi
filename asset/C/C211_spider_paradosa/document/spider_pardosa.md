# 긴마디늑대거미속 (*Pardosa*) — 2DGP 생물 명세서

> **범위:** 늑대거미과(Lycosidae)의 **속** 객체. 크기·번식·계절성은 종마다 달라 고정된 속 공통값이 아니다. 연구에서 확인된 사실과 2DGP 설계 필드를 분리한다.

## 1. 분류·근거 범위
- 분류: 동물계 → 절지동물문 → 거미강 → 거미목 → 늑대거미과 → ***Pardosa* C. L. Koch, 1847**. [P01]
- 국내 예시: 별늑대거미 *P. astrigera*, 가시늑대거미 *P. laura*, 들늑대거미 *P. pseudoannulata*. 국내 출현과 특정 연못 출현은 별개다. [P02][P10]
- **근거 구분:** `[속 연구]` 속 개체 조사 / `[종 사례]` 특정 종 결과 / `[과 일반]` 늑대거미 일반 / `[미확인]` *S. aquaticus* 직접 포식 등.

## 2. 크기·외형·감각
| 요소 | 확인된 내용·범위 |
|---|---|
| 몸길이 | *P. amentata*: 수컷 **5.5–6.5 mm**, 암컷 **6.0–8.0 mm**; *P. agrestis*: 수컷 **4.5–5.0 mm**, 암컷 **약 5.0 mm**. 모두 **종별 성체 사례**이며 다리 제외. [P03][P07] |
| 체형·색 | 머리가슴과 둥근 배, 8개 다리. 갈색·황갈색·회갈색 바탕에 줄무늬·반점; 종·암수·개체별 변이. [P03][P04] |
| 눈 | 늑대거미형 **4:2:2** 배열: 앞쪽 작은 눈 4개, **큰 후중안(PME) 2개**, 뒤가쪽 후측안(PLE) 2개. 큰 눈을 전중안으로 쓰지 않는다. [P04][P12] |
| 입·감각 | 위턱/독니로 제압, 다리 감각털로 진동·접촉 탐지; 시각·기질 진동은 사냥과 구애에 관여. 정량 탐지거리 미확인. [P04][P09] |
| 실·촉지 | 실젖은 이동실·난낭에 사용; 먹이 포획용 정착그물은 일반적으로 없음. 성숙 수컷 촉지는 정자 전달기관. [P04] |
- 새끼 크기, 질량, 다리 편 길이, 독량·이동속도는 **속 공통 수치 미확인**.

## 3. 서식·이동·행동
- **서식:** 풀밭·농경지·낙엽층·흙바닥·물가 등. *P. amentata*는 습한 곳, *P. agrestis*는 건조한 개방지에도 산다. **속 전체를 습지 전용으로 설정하지 않는다.** [P03][P07]
- **사냥:** `탐색/대기 → 방향 전환 → 접근·돌진 → 다리·위턱으로 제압 → 섭식`; 그물 포획보다 지표 배회·기습 중심. [P04][P06]
- **회피:** 경계 시 달리거나 식생·틈으로 숨을 수 있음. 활동 시간대와 반응거리 등은 종·환경에 의존한다. [P04]
- **수면:** *P. amentata*의 수면 접촉 장면은 참고 가능하나 *Pardosa* 속 전체의 지속 수면 보행·수중 추격 능력은 **미확인**. [P15]
- **분산:** 일부 늑대거미 유체의 실 이용 공중분산은 알려졌으나, 모든 성체의 고정 능력이 아니다. [P08]

## 4. 먹이·생태적 역할
- 작은 절지동물(톡토기, 진딧물, 소형 파리·노린재 등)을 먹는 **일반 포식자**. 먹이 종류·비율은 종 및 서식지에 따라 달라진다. [P05][P06]
- **톡토기 DNA 확인:** 스웨덴 경작지·초지 연구에서 늑대거미 **469개체**를 조사했고, *Pardosa*의 톡토기 DNA 양성은 약 **20%**(초지 19%, 곡물밭 22%). 이는 **해당 연구의 검출 빈도**이지 성공률·일일 섭식량이 아니다. [P05]
- 2022년 영국 경작지의 5개 거미 속(이 중 *Pardosa* 포함) 연구는 300개체를 처리해 244개체의 유효 식성 자료를 확보. 먹이 분류단위 89개는 **5속 합계**다. [P06]
- 개체 자신의 천적(새, 양서류, 대형 절지동물 등)과 지역별 해충 억제 효과는 **종별 정량 근거 미확인**.

## 5. 생식·성장
- **구애:** 수컷 앞다리·촉지 움직임, 기질 진동 등 시각·진동 신호; 유럽 *Pardosa* **26종 비교**에서 종마다 신호가 달랐다. [P09]
- **교미·알:** 수컷 촉지로 정자 전달; 암컷은 난낭을 실젖에 달아 운반하고, 부화한 새끼를 등에 태우는 늑대거미형 모성행동. [P04][P08]
- **종별 연구:** *P. saltans* 난낭 관리 약 **30일** 사례 [P13]; *P. pusiola*의 침수·위험 자극 반응 연구 [P14]. 다른 *Pardosa*에 일괄 적용 금지.
- **발육:** 알 → 새끼 → 반복 탈피 → 성체. *P. mackenziana*는 지역에 따라 1년·2년 발육 사례가 있으나 속 전체 수명 기준이 아니다. [P08]
- 한 번의 산란수·성숙 소요일·성체 수명·월동 단계: **종·지역별 확인 필요**.

## 6. `toktogi`(*Sminthurides aquaticus*) 관계
| 연결 | 판정 |
|---|---|
| 톡토기류 → *Pardosa* | **속 수준 근거 있음**: 먹이 DNA 검출 [P05] |
| *S. aquaticus* → 미동정 거미 | **대상 톡토기의 포식 사진 기록 있음** [P11] |
| *S. aquaticus* → *Pardosa* | **미확인 후보**: 사진의 거미가 이 속으로 동정되지 않음 |
| 톡토기 알 포식·수면 추격·포획률 | **미확인**; 신체 크기 비교로 추론 금지 |

## 8. 검증·관찰 우선순위
- **종 동정:** 눈(특히 PME/PLE), 무늬, 성숙 수컷 촉지·암컷 생식판, 몸길이·성별·성숙도 촬영.
- **서식지:** `ground/leaf/wet_bank/floating_plant/water_surface`를 분리; 같은 날·장소의 거미·톡토기 동시출현 기록.
- **포식:** 먹이 종 동정 후 `조우→공격→물기→섭식/방출`을 연속 기록. DNA 양성·접촉·포식 성공을 혼동하지 말 것.
- **미확인 고정값 금지:** 개체당 먹이량, 일률적 야행성, 속 평균 수명/속도, *S. aquaticus* 전용 포식확률.
